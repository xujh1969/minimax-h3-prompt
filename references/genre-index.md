# 题材反向索引（L1 入口 · 每次先读这一页）

> **用法**：从用户故事里识别题材 → 在下方命中文件 → **只加载那一个** → 再写提示词。
> 命中不了用「插值」（见第六节）。**不要一次性加载多个题材文件**（浪费上下文、参数会打架）。

本技能参考库是 **四层结构 + 两维正交叠加**，加载顺序固定为 **题材 → 结构 → 风格**，介质/视觉风格/年代作为正交维度在确定题材后叠加：

| 层 | 文件 | 管什么 |
|---|---|---|
| **L1 题材**（核心语法） | `genre/*.md`（13 个专类 + 长尾 5 主题子集 `long-tail-{people,stage,media,commercial,special}.md` 共 52 子类） | 题材专属：ASL / 色温 / 光比 / 景别 / 母题动词 / 翻车点 |
| **L2 结构**（广告叙事） | `commercial-ad-structures.md` | 8 种广告结构曲线，与题材**正交叠乘**（题材管风格，结构管顺序） |
| **L3 风格**（导演/摄影） | `director-anchors-western.md` / `director-anchors-asian.md` / `dp-cinematographer-anchors.md` | 用户点名导演/影片时才读，只做句尾点缀锚点 |
| **L4 介质**（拍摄载体） | `medium/mobile-ugc.md` / `medium/found-footage.md` / `medium/action-cam.md` | 手机自拍 / 监控DV / 运动相机语法的正交叠加 |

**两维正交（不独占文件，按需叠加到任何题材）**：
- **视觉风格** `visual-style.md`：16 种画风（日式赛璐璐 / 吉卜力 / 新海诚 / 京都 / 押井守赛博、美式 TV 卡通 / 迪士尼 / 定格 / 水墨 / 皮影 / 像素…）——动漫（日/欧美）的画风根在此。
- **年代质感** `era-period.md`：12 个时代滤镜，给任何题材叠时代层。

> ⚠️ **战争 ≠ 动作武侠**，切勿误载 `action-wuxia.md`。武侠目标=让观众看清全身招式（全景必备、轴线锁死）；战争目标=信息剥夺（每镜不给完整信息、刻意失焦）。两者景别与运镜逻辑完全对立。
> ⚠️ **悬疑/惊悚分层**：轻悬疑氛围走 `horror-thriller.md`；刑侦/命案/黑帮走 `crime-thriller.md`；两者可叠加。
> ⚠️ **动漫分流**：画风根在 `visual-style.md`（日式赛璐璐/吉卜力 vs 美式 TV 卡通/迪士尼）；动画/二次元的**题材节奏母题在 `genre/long-tail-special.md`**（其关键词含"动画/二次元"）。要"动漫感"需同时看 `visual-style.md`（画风）+ `long-tail-special.md`（节奏）。`long-tail-genres.md` 是**跨题材插值示例附录**（如"宠物粮广告=食品光色×宠物节奏×产品收尾"），做交叉题材插值时见第六节并加载它。

**广告叠加**：出现 广告 / TVC / 品牌片 / 种草 / 卖点 / 转化 / 信息流 / slogan / logo → **额外**加载 `commercial-ad-structures.md`，与题材正交叠乘。
**导演/影片风格**：用户点名导演、片名或"XX 那种感觉" → 加载 `director-anchors-western.md` / `director-anchors-asian.md`（或摄影 `dp-cinematographer-anchors.md`），只做句尾点缀。
**介质叠加**：手机自拍 / 监控DV / 运动相机 → 加载 `medium/*` 对应文件。
**视觉风格叠加**：用户要"吉卜力/迪士尼/像素风…" → 加载 `visual-style.md` 取画风基底（写在句首）。
**年代叠加**：用户要"80 年代/赛博朋克 2099/民国…" → 加载 `era-period.md`。

## 四、A/B/C 三方案（默认执行）

**除非用户已明确指定风格/导演**，写提示词前先给三条**截然不同**的路线，每条三行，让用户挑：

```
A · 写实纪实向  —— 一句话画面 ｜ ASL / 光色 / 关键手法
B · 风格化作者向 —— 一句话画面 ｜ ASL / 光色 / 关键手法
C · 极简高级向  —— 一句话画面 ｜ ASL / 光色 / 关键手法
```

规则：
- **三条必须真的不同**（节奏 + 光色 + 景别策略三者都要有差异），不能是同一方案换措辞。
- 每条 ≤3 行，不展开。用户选定后才写完整提示词。
- 用户说"随便/你定"→ 选 A（最稳），并说明理由一句。
- 用户已点名导演、影片、或给了明确风格描述 → **跳过此步**，直接写。

## 六、插值指南（题材没命中时）

任何题材都可拆成四个维度，各自从最近的核心题材借。**需要跨题材综合示例与插值硬规矩时，加载 `genre/long-tail-genres.md`（跨题材示例附录：宠物粮广告/健身房/中医品牌片的四维拼法 + 插值三条铁律）。**

| 维度 | 问自己 | 去哪借 |
|---|---|---|
| **节奏** | 这事发生得快还是慢？ | 快→action / 慢→landscape、emotional |
| **光色** | 观众该觉得暖还是冷、亮还是暗？ | 暖食欲→food / 冷精密→product、scifi、tech-corporate / 暗压抑→horror、crime、war |
| **景别** | 要看细节还是看关系还是看尺度？ | 细节→food、product / 关系→emotional、documentary / 尺度→landscape、scifi、war 战役层 |
| **结构** | 是广告吗？要转化吗？ | 是→commercial-ad-structures 选范式 / 否→按题材自然顺序 |

**示例**
- 宠物粮广告 = `food` 的光色（暖逆光、油润质感）× `long-tail 儿童宠物` 的节奏 × `product` 的成品英雄镜 × `问题—解决` 结构
- 健身 APP 信息流 = `action-wuxia` 的长短交错 × `fashion-beauty` 的身体动势 × `KOL 口播` 结构
- 银行品牌片 = `documentary` 的真实感布光 × `emotional-family` 的克制节奏 × `情感微电影` 结构
- 抗战题材短片 = `war-military` 的信息剥夺 + 二战 5000–5600K 去饱和 × `era-period` 民国/抗战层 × 可选 `found-footage` 8mm 颗粒
