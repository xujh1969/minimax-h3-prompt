# 动画十二原则（迪士尼）→ H3 可观察提示词映射

本文件把迪士尼经典动画十二原则，转译为 **MiniMax H3 能直接看见的动作语言**。它与 `genre/*.md`（题材层）正交：题材管风格与节奏，本文件管「动作怎么写得可信、有重量、有生命感」。

## 何时加载

当请求涉及以下任一项时，在命中题材文件后**额外加载**本文件（与题材正交，不受「只加载一个」限制）：

- 角色表演 / 肢体动作 / 表情变化（走 / 跳 / 挥击 / 转头 / 伸手 / 大笑）
- 环境动态（风、水、雾、粒子、树叶、旗帜的层次运动）
- 首尾帧过渡（FL2VA · ③ 模式）
- 产品 / 静物展示动效

> 加载后，把本文件的**具体规则**以「效果」形式织入 `integrated_multimodal_description:` 的各 `[Shot n]`（见 SKILL 步骤 3.4 的「以效果织入」铁律），不要照抄原则名称。

## 1. 十二原则 → 可观察语言映射表

不要只写原则名，要翻译成模型看得见的运动。

| 需求 | 优先原则 | 可观察的提示语言（写进 [Shot n]） |
|---|---|---|
| 起跳、冲刺、挥击 | 预备动作(anticipation)、弧线(arc)、缓入缓出(ease)、时间控制(timing) | 先压低重心蓄力；身体沿清晰弧线发力；启动短促、落地回弹后稳定 |
| 柔软、弹性、碰撞 | 挤压与拉伸(squash&stretch)、扎实造型(solid drawing)、时间控制 | 接触瞬间轻微压缩，离开时适度拉伸；保持总体体积与角色结构 |
| 转头、挥手、走路 | 弧线、重叠动作(overlapping)、跟随动作(follow-through) | 手臂与头部沿自然弧线；发梢、衣摆晚半拍跟随并渐停 |
| 表情与情绪变化 | 舞台调度(staging)、夸张(exaggeration)、吸引力(appeal)、次要动作(secondary) | 先让视线引导注意，再放大眉眼与嘴角；用手指、小幅呼吸或姿态补充情绪 |
| 环境动态 | 次要动作、重叠动作、缓入缓出 | 风先推动近处叶片，再传到衣摆与远处树梢；不同元素错峰响应 |
| 首尾姿势衔接 | 关键姿势(key poses)、预备动作、时间控制、缓入缓出 | 设清晰起始姿势、中间关键姿势、目标姿势；每次重心转移都有准备与收势 |
| 产品 / 静物展示 | 舞台调度、弧线、缓入缓出、扎实造型 | 主体轮廓始终清晰；镜头沿单一平滑路径移动；比例与材质稳定 |

**夸张幅度控制**：
- 微妙写实动作 → 用轻微形变 + 克制表情。
- 卡通 / 喜剧 → 可放大预备姿势、节奏反差与轮廓，但**仍须保持体积、关节与重心可信**（不能为了夸张把人拉长或关节折断）。

## 2. 单镜时间节拍（连续镜头，H3 绝对时间戳）

把动作拆成「建立 → 预备 → 主动作 → 跟随 → 缓出」五段，避免动作瞬间发生。下方为常用时长模板（括号内为建议绝对时间戳，写作 `[Shot n]` 时替换 `At MM:SS.mmm`）：

**5 秒简单动作**
- 0.0–0.8s：建立姿势 + 预备动作（压低重心 / 吸气 / 抬眼）
- 0.8–3.2s：完成主要动作，用清晰弧线与速度变化
- 3.2–4.3s：跟随动作 + 环境次级响应（衣摆、发梢渐停）
- 4.3–5.0s：缓出、收势、稳定结尾

**10 秒小情节**
- 0.0–1.5s：建立主体、情绪与空间关系
- 1.5–3.0s：预备动作或事件触发
- 3.0–7.0s：主动作与情节变化
- 7.0–9.0s：反应、跟随动作与环境反馈
- 9.0–10.0s：收束，停在清晰、有吸引力的姿势

**15 秒**（小情节扩展）：按比例拉长中段，但首尾「建立 / 收束」各留 ≥1s 稳定。

> 多镜分段时，每镜内部仍套此节拍；动作戏（命中 `action-wuxia.md`）按该文件更细的镜长交错规则执行。

## 3. 跟随动作 / 重叠动作 / 次要动作（最易被忽略的自然感来源）

自然感几乎都来自「非刚性跟随」：

- **跟随动作(follow-through)**：主体停下后，头发、衣摆、围巾、道具继续运动一会儿再停。例：`她的发梢在整个人停住后还轻晃了两下才静止`。
- **重叠动作(overlapping action)**：身体各部分不同时启动、不同时停止。例：`手臂先抬起，肩膀与头部晚半拍跟上`。
- **次要动作(secondary action)**：主动作之外的小动态强化情绪，不抢戏。例：说话时手指无意识捻衣角、等待时脚尖轻点地。
- **环境错峰响应**：风 / 冲击波先动近处元素，再传中景，最后远树梢；各层幅度与速度不同，形成空间深度。

## 4. 挤压与拉伸（体积守恒）

碰撞 / 落地 / 弹跳瞬间：接触点附近轻微**压缩**，离开时**拉伸**，但**总体体积与角色结构保持不变**。写进对应 `[Shot n]`：`落地瞬间膝盖微屈、身体轻压，随即弹起时纵向拉伸`。

## 5. 表情与吸引力（staging / exaggeration / appeal）

- **视线先引导**：先写「目光看向 X」，再写「眉眼嘴角随之变化」，引导观众注意力。
- **吸引力**：收尾停在「有性格、有呼吸感」的姿态而非僵直；可用小幅呼吸、重心微移维持活人感。
- **夸张有度**：看上面「夸张幅度控制」——写实克制、卡通放大但可信。

## 6. 运镜复杂度 × 动作复杂度 = 反向关系（镜头强度）

- 角色**大幅运动**（跑、跳、打）→ 用**稳定机位或轻微跟随**，让动作当主角。
- 角色**只有微表情 / 小动作** → 才用缓慢推近 / 横移 / 环绕补戏。
- **禁止**同一条提示词里同时写「推近 + 拉远 + 环绕 + 快速摇摄」——运镜与动作会互相抢注意力。

## 7. 首尾帧（FL2VA · ③ 模式）衔接铁律

- **开头短暂停留**：首帧建立后留 0.3–0.8s 静止 / 微动，让模型锚定起点（不要一上来就猛动）。
- **结尾缓出稳定**：最后 0.5–1s 减速并稳定贴合 `<Picture 2>` 的姿势 / 状态 / 光线，不甩出画面、不突变。
- **中间必须是因果过程**：起始姿势 → 预备 → 中间关键姿势 1 → 中间关键姿势 2 → 主动作 → 落到尾帧；每次重心转移都有明确受力与缓入缓出。
- **禁止**：用溶解 / 闪白 / 遮挡 / 瞬间变形 / 无理由切镜掩盖衔接。两帧差异过大或尾帧只能靠突变到达时，先在生成依据里向用户指出风险，并设计合理中间动作。

## 8. 环境动态层次（near → mid → far 错峰）

单镜头环境动画：动态从触发源开始，先影响近处元素，延迟传到中景与远景，各层幅度 / 速度不同。光影 / 雾气 / 水面 / 粒子以缓入缓出方式变化，最终自然回落。镜头静止或一个缓慢运镜，不改变场景结构，不背景漂移 / 纹理闪烁。

## 9. 动画专项自检清单（交付前逐项确认）

- [ ] 什么必须保持不动、什么要动，是否清楚？
- [ ] 动作是否具备「准备 → 主动作 → 跟随 → 收势」，而非瞬间发生？
- [ ] 动作路径、重心、受力、速度变化是否可信？
- [ ] 是否只选了真正相关的原则并转成**可观察语言**（而非堆原则名）？
- [ ] 运镜是否**只有一个主要方向**，且不与角色动作争夺注意力（反向关系）？
- [ ] 环境动态是否有**先后与层次**（错峰），而非全部同步循环？
- [ ] 跟随 / 重叠 / 次要动作是否补上（发梢、衣摆、小手势）？
- [ ] 首尾帧：开头是否短暂停留、结尾是否 0.5–1s 缓出稳定贴合尾帧、中间是否为因果过程？
- [ ] 约束是否针对当前风险且 ≤5 项，且写的是正向状态（非否定句式）？
