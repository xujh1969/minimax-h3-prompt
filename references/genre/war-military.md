# 题材语法手册 · 战争 / 军事 / 冲突 War & Military

> **一句话定性**：战争片卖的不是"打得帅"，是**信息剥夺带来的恐惧**。你的任务是让观众和士兵一样，**不知道威胁从哪来**。
> 所有决策都回到一个问题：**这个镜头是不是给多了？观众是不是看得太清楚了？**

> ## ⚠️ 警示：**绝对不要套用动作/武侠的法则**
> 这两个题材的第一性原理**恰好相反**，误用会把战争拍成廉价爽片：
>
> | | 动作 / 武侠 | 战争 / 军事 |
> |---|---|---|
> | 核心目标 | **信息给足** —— 让观众看清全身招式 | **信息剥夺** —— 每镜都不给完整信息 |
> | 景别 | 全景必备，交代身体与空间关系 | 大量 CU/MCU 遮挡，全景只在"战役层级"给 |
> | 轴线 / 完整性 | 轴线锁死、招式必须打完不切碎 | 方向感可被故意打乱；**刻意切碎、失焦、错过** |
> | 升格 | 用在招式最帅的顶点 | **禁止用在冲锋** —— 只给死亡与耳鸣段 |
> | 镜头 | 稳、准、可读 | 脏、抖、被震到、镜头上有泥点 |
>
> **武侠让你成为观众，战争让你成为当事人。**

## 1. 母题动词 ×5（点火器 — 灵感全在动词里，不在形容词里）

| 动词 | 物理含义 | 典型镜头 |
|---|---|---|
| **躲避 Take cover** | 身体对威胁的本能反应 | 士兵扑进弹坑、贴墙缩身、头猛地低下 |
| **掠过 Snap past** | 看不见的威胁经过 | 子弹擦过耳侧带起气流、弹道划开水面、碎屑从画面外飞入 |
| **推进 Advance** | 在恐惧中仍向前 | 弯腰小跑穿过开阔地、跟随镜头贴在背后 |
| **炸开 Blow apart** | 环境瞬间失控 | 土柱腾起、墙体粉碎、人被冲击波掀翻出画 |
| **搜索 Scan** | 找不到敌人 = 恐惧本身 | 枪口与视线同步扫过废墟、镜头快速摇过空无一人的街道 |

**用法**：写提示词前先选 **2–3 个动词**当骨架，选不出来 = 这条片子只是"穿军装的人在放烟花"。"惨烈的/史诗的/震撼的/热血"这类词对模型**只会触发游戏 CG 缩略图**，动词才能长出画面。

## 2. 灵感种子 ×3（具体到可直接拍）

1. **「威胁在画外」** — 全片不出现敌人。士兵贴在断墙后，镜头贴着他的肩，画面另一半是空荡的街道；子弹打在墙上溅起碎屑三次，方向一次比一次近。**恐惧全部由画外音和碎屑落点完成**。
2. **「一次冲击波」** — 前 3 秒是正常的行进环境声与脚步；一次爆炸后立刻切成高频耳鸣 + 闷响，环境音全部剥离，画面转半速，士兵张嘴喊叫但听不见；4 秒后声音"漏"回来，画面回到正常速度。
3. **「泥泞里的一分钟」** — 固定低机位贴地，画面下半部全是泥浆。士兵的靴子一个接一个从镜头前踩过，泥水溅上镜头留下污点不擦。整片只有一个镜头，靠**镜头脏污的累积**表达时间与消耗。

## 3. 必备镜头清单（不拍就不像战争片）

| # | 镜头 | 要点 |
|---|---|---|
| 1 | **贴身手持跟随** | 摄影机贴在士兵背后半米，随他呼吸与奔跑一起抖。**观众的身体位置=士兵的身体位置** |
| 2 | **被震到的机身** | 爆炸瞬间镜头被物理冲击带偏、失焦 0.5s 再找回。**穿帮就是真实感** |
| 3 | **画外威胁的物证** | 不拍敌人，只拍子弹打中的落点、碎屑、扬尘、水花。**威胁越不可见越可怕** |
| 4 | **遮挡构图** | 前景有断墙/烟/战友后背挡住 40% 以上画面，观众只能从缝隙里看 |
| 5 | **脏镜头 ECU** | 镜头上的泥点、血渍、水珠、划痕，**不擦掉**，让它挡住一部分主体 |
| 6 | **规模揭示（仅战役层级）** | 高位广角或航拍，人海、烟柱、弹坑地貌一次性交代尺度；可选**死亡的静止**——唯一允许升格的时刻 |

## 4. 开场钩子 ×2（前 2 秒抓人）

- **A · 声音先于画面到达**：黑场中先给远处的闷响 thump 与颤抖的呼吸声 1.5s，画面才亮起。**听觉威胁比视觉更快建立恐惧**。
- **B · 极端局部**：开场是发抖的手在给弹匣压子弹（ECU，f/1.8），第 2 秒一声超音速 crack 从画外炸响，手一顿。**先建立脆弱，再引入威胁**。

## 5. 节奏 ASL 与结构曲线（**三个规模层级是三套完全不同的拍法；先确定层级再动笔，层级错了所有参数全错**）

| 层级 | 单兵 Individual | 班组 Squad | 战役 Battle |
|---|---|---|---|
| 机位 | 贴身手持，肩后 0.5m | 跟随中景、越肩 | 高位广角 / 航拍 / 长焦压缩 |
| 景别 | CU / MCU 为主 | MCU / MS 为主 | ELS / LS 为主 |
| ASL | **0.8–1.5s** | **1.2–2.0s** | **2.5–4.0s** |
| 焦段 / 光圈 | 24–35mm，f/1.8–f/2.8（浅到只有一只眼清晰） | 35–50mm，f/2.8–f/4 | 18mm 或 200mm，f/5.6–f/8 |
| 核心感受 | 呼吸声、耳鸣、看不见敌人 | 交叉火力的方向感、互相呼喊 | 人海与烟柱的尺度、人的渺小 |
| 声音重心 | 呼吸、心跳、装备摩擦、耳鸣 | 多方向枪声、无线电、喊话 | 连绵炮声、远处轰鸣、低频 |

**10s 结构曲线 · 单兵**
```
0–1.5s   脆弱建立（发抖的手 / 呼吸）  2 镜，0.7s，ECU，手持
1.5–4s   威胁降临（画外 crack + 躲避） 3 镜，0.8s，CU，被震到、失焦
4–7s     耳鸣段（半速 + 声音剥离）     2 镜，1.5s，MCU，眼神空洞
7–10s    声音漏回 + 再次推进           2 镜，1.5s，MCU→MS，跟随背影
```

**10s 结构曲线 · 班组**
```
0–2s     行进（跟随背影穿过废墟）      1 镜，2.0s，MS，稳定手持
2–5s     接火（左右两侧火力方向）      2 镜，1.5s，越肩，轴线交替
5–7.5s   一人中弹 / 队形溃散           2 镜，1.2s，MCU，1 次升格给倒下
7.5–10s  重新集结（喊话 + 烟雾遮蔽）   1 镜，2.5s，MS，横移
```

**10s 结构曲线 · 战役**
```
0–3s     地貌揭示（航拍掠过弹坑地表）  1 镜，3.0s，ELS，恒速平飞
3–6s     人海尺度（长焦压缩推进队列）  1 镜，3.0s，LS，200mm，几乎静止
6–8.5s   炮火落点（远处烟柱连续腾起）  1 镜，2.5s，ELS，静止
8.5–10s  切回单兵（一张脸 / 一双眼）   1 镜，1.5s，CU，反差收口
```

- **总镜头数 10s**：单兵 ≤ 9 镜，班组 ≤ 7 镜，战役 ≤ 5 镜。**战役层级必须以一个单兵 CU 收口**，否则尺度感变成沙盘演示，与观众无关。

**时长拉伸与幕次叙事结构（防定格灌水 / 生硬拼接）**

快节奏绝不等于可以生硬拼接或跳跃——整体情节发展必须有顺序因果，每幕之间靠"承上"的镜头衔接，不能拿重复广角或静态定格硬撑时长（这条原则对所有题材通用，动作戏翻过车，战争戏同样会翻）。

- **容量警戒**：战争片每段的有效内容其实很"短"。单兵 10s 的 9 镜、班组 7 镜、战役 5 镜都已经饱满；强行拉到 12–15s 而不扩展内容，模型只会用**同一广角定格重复**或**画外威胁物证循环**填充——后段空转、情节跳跃断因果，上一版咏春群战 15s 的翻车根因正是如此。
- **≥12s 必须拆幕次铺连续因果**（以单兵为例，5 幕 × 3s，每幕都"承上"）：
  1. 0–3s：**脆弱建立**（发抖的手 / 急促呼吸）→ 画外 crack 逼近，第一次躲入掩体
  2. 3–6s：**威胁降临**（弹着点物证 + 被震到的机身失焦）→ 第二次躲避 / 搜索方位
  3. 6–9s：**耳鸣段**（半速 + 声音剥离）→ 队友中弹或队形变化，交代去向
  4. 9–12s：**声音漏回** → 再次推进 / 交叉火力方向确认
  5. 12–15s：**活态收束**——烟柱仍在上升、雨/灰仍在落、士兵仍在颤抖呼吸、镜头缓慢推离；**禁止无微动的纯静态定格或重复广角**
- **活态收束（战争版）**：用「持续的环境微动」收尾（烟、雨、灰烬、人物呼吸起伏），而不是武侠式的"收势亮相"。战争片结尾可以是"声音渐弱但画面仍在动"，与耳鸣/空镜形成反差，反而更克制有力。
- **硬约束写法**：
  - `PRESERVE`：每幕之间必须有"承上"镜头（上一幕的动作 / 方位 / 人物在下一幕延续）；结尾保持活态（烟 / 雨 / 灰 / 呼吸仍在微动）。
  - `AVOID`：同一广角画面重复超过 1 秒；用无微动的纯静态定格填充结尾；无任何动作变化的空镜超过 1.5s；幕间靠"硬切跳时间"而非动作连贯推进。

## 6. 景别策略

- **单兵/班组的主战场是 CU / MCU**，且**每一镜都被遮挡**：烟、前景、战友、器材挡掉 30%–50% 画幅。
- **全景是稀缺品**：只有战役层级才配 ELS。在单兵段落插入干净全景 = 把观众从当事人变回观众，恐惧当场归零。
- 相邻景别**不必跳级**，战争片允许 CU→CU 连续，靠**方向混乱与遮挡差异**区分。
- 单兵视角**不给"看清整个战场"的镜头**：士兵看不见战场，观众也不该看见；结尾用一个眼睛或一双手的 CU 收口，比任何全景都重。

## 7. 运镜偏好

| 推荐 | 英文 | 用途 |
|---|---|---|
| 贴身手持跟随 | handheld follow, tight on the shoulder | 单兵/班组主力运镜，随呼吸起伏 |
| 被冲击带偏 | camera knocked off-axis by blast | 爆炸瞬间，含 0.3–0.8s 失焦再找回 |
| 慌乱找焦 / 快速摇摄 | frantic rack focus, fast whip pan searching | 威胁方向不明时替观众"找"，**不用于展示动作** |
| 越肩跟随 | over-the-shoulder tracking | 班组层级，保留火力方向感 |
| 恒速航拍平飞 | steady aerial glide | **仅限战役层级**，速度匀且慢 |
| 长焦压缩静止 | 200mm compressed, locked-off | 战役层级人海，压缩使队列密不透风 |

**禁用**：轨道稳定推拉、精确环绕、无动机变焦炫技、平滑斯坦尼康长走位（除非明确做"战场巡礼"的反差段）。**理由**：稳定的运镜暗示"有人在从容地拍摄"，而战场上没有从容。**镜头必须显得是被人扛着、被爆炸推着、被恐惧带着走的**。

## 8. 光位与色温（**时代分层：不同战争是不同的光**）

- **核心光位：单一自然主光（太阳/火光/照明弹）+ 大面积不补光**，光比 **6:1 ~ 10:1**，暗部允许死黑。脸的一半沉进阴影是常态，看不清人是特征不是缺陷。
- **烟与尘是唯一的柔光板**：所有光必须穿过介质。写 `heavy smoke, drifting dust, backlit haze`。
- **绝对禁止**：广告式三点布光、发型光、干净的眼神光、蓝色夜景补光把暗部照亮。

| 时代 | 光源与色温 | 质感特征 |
|---|---|---|
| **冷兵器** | 纯自然光；夜战靠火把 **1800–2000K** | 扬尘密布、皮革与铁锈、雨天泥地、无镜头光晕 |
| **一战堑壕** | 阴天顶部漫射 **6500–7000K**，无直射日光 | 灰绿调、泥浆反光、**毒气黄绿雾**、几乎无饱和度 |
| **二战** | 硬质日光 **5000–5600K**，室内钨丝 3000K | 去饱和、柯达褪色感、暖褐与卡其、中等颗粒 |
| **越战** | 强烈直射日光 + 丛林透射绿 **5600K** | **高饱和绿**、潮湿高光、明显胶片颗粒、镜头眩光可留 |
| **现代** | 数字冷调 **6000–7000K**；夜视绿、热成像白 | 低饱和青灰、锐利、夜视段落单色绿并带噪点 |
| **近未来** | 无人机顶光 + HUD 自发光 + 激光 **7000K+** | 冷蓝紫、屏幕叠加、扫描线、画面内嵌 UI 与坐标 |

## 9. 色彩与质感

> **45° 快门角度是战争片的技术核心。** 正常用 180° 快门（1/48s @24fps）带自然运动模糊；收到 **45°**（约 1/192s @24fps）后每帧极锐、帧间出现**跳格般的频闪**，碎屑与水花边缘变成**硬边**，观众被迫一帧帧"看清"暴力 —— 这是《拯救大兵瑞恩》以来战争片的标准语法。写法：`45-degree shutter angle, staccato strobing motion, hard-edged debris`。**只用在战斗段落**，文戏与静默段回到 180°，否则全片像故障。

- 调色：**去饱和为基调**，只保留 1–2 个色相有饱和度（火焰橙、毒气黄绿、夜视绿、血的暗红）。
- **画面必须脏**：镜头上的泥点血渍、被震到的机身位移、穿帮的失焦。**这不是瑕疵，是真实感的物理来源** —— 干净的战争画面 = 游戏 CG。
- 质感：**胶片颗粒必写**（二战/越战中粗、现代细）+ 轻微色差与边角失光 vignetting；高光可**过曝到死白**，烟雾被逆光打穿时的过曝是战争摄影的签名（见 Janusz Kamiński）。空气永远浑浊：烟、尘、雨、雪、灰烬，**清澈空气的战场不成立**。

## 10. 升降格用法（**战争片禁止英雄式升格**）

> 升格 = 让观众欣赏；战争片不需要观众欣赏，只需要观众承受。**把升格用在冲锋、开枪、爆炸本身，画面立刻变成廉价爽片。**

| 瞬间 | 速度 | 效果 |
|---|---|---|
| 死亡瞬间 | 1/2 (48–60fps) | **唯一允许的情绪升格**，身体缓慢失去支撑 |
| 耳鸣段落 | 半速 (50%) | 与声音剥离同步，制造"意识脱离"的主观感 |
| 冲锋 / 奔跑 | **正常速度 + 45° 快门** | 频闪硬边，比升格更暴力也更真实 |
| 开枪 / 中弹 / 爆炸主体 | **正常速度** | 暴力必须是突然的；慢下来就变成焰火表演 |
| 被掀翻的人 | 正常 或 1/2 抽 3–5 帧 | 抽帧比升格更粗暴，保留失控感 |
| 灰烬 / 雪 / 纸片飘落 | 1/2 (60fps) | 战斗**结束后**的空镜，与前段形成静默反差 |

## 11. 声音设计（战争片的一半在耳朵里）

**枪声是两个声音，别混为一谈 —— 这是战争片音效的专业分野：**

| 声音 | 物理来源 | 提示词写法 | 用途 |
|---|---|---|---|
| **crack** | 子弹以超音速掠过你身边产生的**音爆** | supersonic bullet crack snapping past | 说明"这一发是冲你来的"，近、尖、突然 |
| **thump** | 远处枪口本身的**发射闷响**，晚于 crack 到达 | distant muzzle thump, delayed and dull | 说明"射手在很远的地方"，闷、低、滞后 |

**先 crack 后 thump 的时间差，就是敌人距离的听觉刻度。** 只有 thump 没有 crack = 没打中你附近。

- **耳鸣静音手法（最有效的情绪武器）**：爆炸后 **1.5–3s** 内环境音**全部剥离**，只留**高频耳鸣（约 4–6kHz 正弦）+ 被闷住的低频轰响**，人声模糊如水下，画面同步转半速；之后声音**渐进"漏"回来**（0.5–1s 内从闷到清）而非硬切。
  写法：`tinnitus ring, muffled low-end, all ambience stripped, audio returns gradually`。
- 单兵层级必写**急促呼吸、心跳、装备金属摩擦、靴子踩泥** —— "身体在场"的证据；枪声必须**有方向与回声**（街道回响、室内混响、开阔地无回声），方向感是班组层级的命根子。
- **禁止**：全程铺满英雄主义配乐。音乐只在**战斗结束后的空镜**或**耳鸣段之后**进入，且以单一持续音或极简弦乐为主。

## 12. 翻车点 ×4

1. **给了完整信息** → 观众看清了敌我位置和整个战场，恐惧归零，变成战术演示。**正确做法**：每镜遮挡 30%–50%，威胁只用画外声与落点物证表示，不拍敌人正面。
2. **英雄式升格冲锋** → 立刻变廉价爽片。**正确做法**：冲锋用正常速度 + 45° 快门的频闪硬边；升格只留给死亡瞬间与耳鸣段。
3. **画面太干净** → 无泥点、无颗粒、无失焦、机身纹丝不动 = 游戏 CG。**正确做法**：显式写镜头污渍、被冲击带偏的机身、0.5s 找焦失败、粗胶片颗粒。
4. **爆炸后声音照旧** → 浪费了战争片最强的情绪武器。**正确做法**：爆炸后 1.5–3s 剥离全部环境音，只留耳鸣与闷响，画面半速，然后让声音渐进漏回。
5. **定格灌水 / 生硬拼接** → 强行拉到 12–15s 但内容不扩展，模型用重复广角定格或空镜填充，后段空转、情节跳跃断因果。**正确做法**：≥12s 必须拆幕次铺连续因果（见 §5「时长拉伸与幕次叙事结构」），用「烟 / 雨 / 灰 / 呼吸持续微动」的活态收束替代死定格，避免幕间靠硬切跳时间。

**附加**：不要写"惨烈的/史诗的/震撼的/热血沸腾"这类词，模型无法执行；改写成物理描述（子弹掠过带起气流、镜头被震偏并失焦、烟雾被逆光打到过曝死白）。**也不要混用时代分层的光色** —— 越战的高饱和绿插进二战的去饱和暖褐里，两套语言互相抵消，年代可信度当场消失。

## 13. 可借导演 ×2（L3 点缀，只在末尾加一句）

- **史蒂芬·斯皮尔伯格 + 摄影师 Janusz Kamiński**（《拯救大兵瑞恩》） — **45° 快门角度**的频闪硬边、去饱和褪色调、烟雾被逆光打穿后的**过曝死白**、手持贴身与被溅到的镜头。**战争片真实感的默认答案**。
- **罗杰·迪金斯**（《1917》） — 长镜头调度中的自然光与照明弹光，火光在废墟中的动态明暗、极高的空间连续性。适合"跟随一个人穿过战场"的结构。

**⚠️ 不要与之叠加**：吴宇森/武侠式的完整招式与英雄升格（当场变爽片）、迈克尔·贝式橙青调与光晕轰炸（消灭去饱和的年代感）、韦斯·安德森式对称平光（战争没有对称与柔光）。

## 14. 中英双语锚点句（可直接贴进提示词）

> 手持贴身中近景，24mm，摄影机紧跟士兵肩后半米并随呼吸抖动；他扑进弹坑躲避，画面被前景土坡遮挡近一半；一发子弹以超音速 crack 从画外右侧掠过，碎屑溅上镜头留下泥点不擦；45° 快门角度，运动呈频闪硬边；紧接一次爆炸把机身震偏并失焦 0.6 秒，随后 2 秒内环境音全部剥离，只剩高频耳鸣与闷响，画面转半速；阴天顶部漫射光 6500K，去饱和灰绿调，光比 8:1，暗部压死；空气中有浓烟与浮尘，逆光处过曝至死白；中粗胶片颗粒与边角失光；f/2.0 浅景深。

## 16. 自检清单（生成前逐条过）

- [ ] 选了 2–3 个母题动词，不是靠"惨烈/史诗/震撼"这类标签撑
- [ ] **明确选定了单兵 / 班组 / 战役一个层级**，ASL、焦段、景别没有混用
- [ ] 每一镜都**信息不足**：有遮挡、有失焦、有画外威胁，没有"看清整个战场"
- [ ] 战斗段写了 **45° 快门角度**与频闪硬边
- [ ] **升格只用于死亡瞬间或耳鸣段**，冲锋与开枪是正常速度
- [ ] 有一次**耳鸣静音**处理，且声音是渐进漏回而非硬切
- [ ] 声音区分了 **crack（超音速掠过）** 与 **thump（远处闷响）**
- [ ] 画面是脏的：镜头污渍、机身被震、胶片颗粒、过曝烟雾
- [ ] 按**时代分层**给了对应色温与质感，没有跨时代混色
- [ ] 光比 ≥ 6:1、暗部压死，**没有**广告式三点布光与眼神光
