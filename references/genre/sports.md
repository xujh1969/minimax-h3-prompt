# 题材语法手册 · 体育运动比赛 Sports & Athletics

> **覆盖范围**：球类对抗（篮球/足球/排球/乒乓/网球/橄榄球）、速度/田径（跑步/跨栏/游泳/自行车/赛车/赛艇）、技巧个人（体操/花滑/滑板/跑酷/跳水/攀岩）、第一视角极限（滑雪/冲浪/骑行/翼装）、以及通用「赛事包装/转播语法」（观众席、计分板、慢放回放）。
> **不覆盖格斗类对决** —— 拳击/击剑/摔跤/综合格斗等**一对一近身对抗**走 `action-wuxia.md`（它才是武侠/格斗对决专家，轴线锁死与升格重音逻辑可直接借用）。本文件的「对抗型」特指**球类与团队对抗**，不是肉搏。
> **第一视角极限**（滑雪/冲浪/骑行）建议**叠加 `medium/action-cam.md`** 介质层（GoPro/FPV 鱼眼），见第五节。
> **电竞/电子竞技对战**不在本文件，走 `long-tail-media.md` 的「电竞」节。

---

> ⚠️ **阅读提示**：本文所有 "2s / 每镜 2 秒" 都是**反面教材或最后降级手段**，不是推荐参数。正确节奏见下方呼吸曲线（爆发 0.4–0.9s、重音 0.8–1.2s、常规跟拍 0.6–1.0s）。体育是**全片最快的题材之一**，但"快"必须来自比赛流本身，不是均匀快切。

## 1. 一句话定性

> 比赛的核心不是"好看的动作"，是**悬念与实时感**：观众必须能感知**比分/排名在变、谁占优、何时结束**。把比赛拍成无目标炫技的"运动品牌形象片"是头号翻车——动作再帅，观众不知道谁赢、这球进没进、还剩几秒，等于没看比赛。
> 所有决策回到一个问题：**这一镜，观众知道比赛进行到哪了吗？**

| 症状 | 成因 | 观感 |
|---|---|---|
| 像 MV 不是比赛 | 只有炫技运动，无比分/攻防/计时推进 | 看完不知道谁赢、比分多少 |
| 慢镜过多 | 升格占比过高、未夹常速 | 力量感消失，变成广告片 |
| 空场比赛 | 没给观众席/计分板 | 失去赛事真实感与喧嚣 |
| 卡拍摆拍 | 套用舞台综艺语法（切点严格卡 BPM） | 运动员像在拍舞，不像在打 |

## 2. 母题动词 ×6（点火器 — 灵感在动词里，不在形容词里）

| 动词 | 物理含义 | 典型镜头 |
|---|---|---|
| **冲刺 Sprint** | 水平 Z 轴极速位移，爆发力外显 | Low-angle WS 跟拍，背景拉成横向流线，尘埃/水花被甩在身后 |
| **变向 Cut** | 急停急起 + 横向位移，重心骤变 | 中景侧向横移跟拍（lateral tracking），与运动员同速 |
| **跃起 Leap** | 垂直 Z 轴脱离地面 | 低角仰拍腾空，镜头快速上摇（whip tilt up），把人衬上天空/顶棚 |
| **击打 Strike** | 球拍/脚/手与物体的瞬时接触 | ECU 接触点 240fps，只给 0.4s 实时长度，物理火星/形变 |
| **对抗 Contest** | 两人/两队争夺同一空间与球权 | OTS 过肩 + 中线俯拍交替，交代站位与攻防关系 |
| **完成 Finish/Surge** | 冲线 / 进球 / 锁定胜局 | 终点线急推（snap zoom）+ 升格重音，随后全场反应 |

**用法**：动笔前先选 **2–3 个动词**当骨架。"燃的/精彩的/激烈的"对模型几乎无效，动词与物理量才有效。

## 3.母题动词之外：三类比赛结构（按悬念组织）

| 结构 | 适用 | 组织方式 |
|---|---|---|
| **攻防流**（球类/对抗） | 篮球/足球/排球/乒乓 | 进攻 → 防守 → 转换 → 得分；每段都要有**明确结果**（进球/出界/抢断），不能只有来回 |
| **计时流**（速度/田径） | 跑步/游泳/赛车/自行车 | 起跑 → 途中竞速 → 最后冲刺 → 冲线；用**计时器/名次**做实时锚点，终点线是第一爆点 |
| **难度流**（技巧/个人） | 体操/花滑/滑板/跳水 | 起势 → 高难动作（升格慢镜表现）→ 落地/完成；落地/触地的实拍音画同步点是"重量感"来源 |

## 4. 必备镜头清单（不拍就不像比赛）

| # | 镜头 | 要点 |
|---|---|---|
| 1 | **ELS 场地立威** | 球场/赛道/场馆全景，交代空间、双方阵营与观众席关系 |
| 2 | **跟拍 Tracking/Steadicam** | **体育黄金律：主体在动，镜头必须跟着动**。斯坦尼康/手持跟拍跑动、运球、骑行 |
| 3 | **ECU 细节** | 球鞋钉入地、手腕绷带、计时器跳动、汗珠、球皮纹理——速度/重量的物理载体 |
| 4 | **升格重音镜** | 冲线/进球/落地/击球瞬间降到 1/4 速，0.4–0.8s |
| 5 | **观众席 / 计分板** | **赛事真实感的来源**：看台人浪、计分板跳动、计时器读数，必须可读 |
| 6 | **慢放回放（转播语法）** | 关键进球/冲线用 1 个 0.5–0.8s 重播（可带轻微推近），强化"这是比赛" |
| 7 | **收束信号** | 终场哨/冲线瞬间/庆祝——明确结束态，见下方「好看的动态收束」 |

## 5. 开场钩子 ×2（前 2 秒抓人）

- **A · 入场/热身微动**：ELS 场馆空镜或球员入场，极缓推入；主体有极细微重心移动、球在指尖转、鞋底碾地——**不是死 pose**，而是"即将开始"的张力（见 action-wuxia §5 B 的微动教训）。
- **B · 实时信号先行**：黑场或极浅景深中先给 0.3s 哨声/发令枪/现场欢呼，再切 ECU 计时器跳动或计分板；**听觉+数据钩子比视觉更快**建立"这是比赛"。

## 6. 节奏 ASL 与结构曲线

### 呼吸曲线（四段式，体育版）

```
【蓄势】站位/起跑 ──→【爆发】快切攻防/竞速 ──→【重音】升格冲线/进球 ──→【收束】庆祝/数据定格
 0.8–1.5s/镜          0.4–0.9s/镜              0.8–1.2s/镜（升格）      1.0–2.0s/镜
```

| 段落 | 镜头时长 | 内容 | 运镜 |
|---|---|---|---|
| **蓄势** | 0.8–1.5s | 入场、起跑姿态、裁判鸣哨 | static / 极缓 push in |
| **爆发** | 0.4–0.9s | 一镜一动作（一次运球/一次变向/一次划水），绝不塞两个 | tracking / whip pan / lateral tracking |
| **重音** | 0.8–1.2s | 升格慢镜，冲线/进球/落地的瞬间 | arc / slow tracking |
| **插入** | 0.2–0.4s | 空镜：观众人浪、计分板跳动、水花、尘 | static |
| **收束** | 1.0–2.0s | 庆祝/终场哨/数据定格，保留全场微动 | static 或极缓推入 |

### ASL 参考落点

| 风格 | ASL | 备注 |
|---|---|---|
| 田径/赛车（极限快） | 0.5–0.8s | 全片最快之一，靠竞速本身造速度 |
| 球类对抗 | 0.7–1.0s | 攻防转换 + 跟拍 |
| 体操/花滑（难度流） | 1.0–1.5s | 升格表现难度，镜头更长 |
| **推荐落点** | **0.6–1.0s** | 快而不糊 |

### 硬上限与实时感

**镜头密度 ≤ 1.5 镜/秒（AI 生成硬约束）。** 10s → 最多 15 镜，建议 11–13 镜；超过模型会糊成闪烁。
**升格总时长 ≤ 20–25%**：升格镜必须**前后夹常速镜**，孤立/连续升格 = 广告片而非比赛。**全程都慢 = 全程都不快，也丢了实时感。**

## 7. 景别策略：跟拍关系优先

| 缩写 | 名称 | 体育用途 |
|---|---|---|
| ELS | 大远景 | 场地立威、看台氛围、冲线全景 |
| WS / LS | 全景 | **看清双方站位与战术关系**（体育黄金律：比赛必须有全景） |
| MS | 中景 | 攻防回合、跟拍跑动/运球 |
| MCU | 近景 | 表情、判断、对峙 |
| CU | 特写 | 手腕、脚踝、球鞋、计时器 |
| ECU | 大特写 | 汗珠、球皮纹理、接触瞬间火星、计分板数字 |

**铁律：相邻两镜景别至少跳 2 级。** ✅ WS → ECU（冲线特写）、ELS → MS；❌ MS → MCU（只差一级）。
**跟拍是体育的灵魂**：爆发段以 **tracking（跟拍）/ lateral tracking（侧向同速）/ steadicam（稳定器）/ arc（绕弧）/ whip pan（甩镜）/ snap zoom（终点急推）** 制造机位落差；高角俯拍（中线/篮下）与低角仰拍（腾空）交替。运动镜头之间夹静止镜（ECU 冲击帧、计分板）作参照。

## 8. 运镜偏好：六大经典手法

| 手法 | 要点 | 写进提示词的措辞 |
|---|---|---|
| **1 跟拍 Tracking** | 主体在动镜头必跟，斯坦尼康/手持贴身 | `稳定器跟拍运动员背影 / steadicam follow the runner` |
| **2 侧向同速 Lateral** | 与运动员同速横移，背景拉成流线 | `侧向同速横移跟拍 / lateral tracking at matching speed` |
| **3 终点急推 Snap zoom** | 冲线/进球瞬间急推 + 升格 | `终点线急推并降速（1/4） / snap zoom on the finish line, slow to 1/4` |
| **4 升格重音 Speed ramp** | 关键接触/落地瞬间降速，随即恢复 | `慢动作（1/4 速）/ slow motion at 1/4 speed` |
| **5 绕弧 Arc** | 绕人/绕场半圈，交代空间 | `镜头绕人走弧线 / arc shot around the athlete` |
| **6 转播机位 Broadcast** | 中线俯拍/边线跟拍/篮下仰拍，建立"这是比赛" | `中线高位俯拍交代攻防 / high-angle midline broadcast frame` |

> **机位要"落差"、忌死板**：不能全程平视固定。运动镜头之间必须夹静止镜（ECU 冲击帧、计分板特写）作锚点，否则观众无参照。

## 9. 光位与色温

- **场馆主灯 5600K 硬光直打**：制造清晰边缘与汗光、球鞋高光，这是体育的"速度物理来源"。
- **看台环境 6500K 偏冷**：场馆本就混光，**允许主灯与看台不同温**（真实场馆本来就混），不必强行统一。
- **日光场（田径/户外）**：4500–5600K 日光，硬光穿云，丁达尔可选；草坪/跑道高饱和。
- **夜场泛光（足球/赛车夜战）**：顶光 + 四周低位泛光，主体亮、背景压暗，光比 4:1–6:1。
- **室内馆（篮球/体操）**：5600K 均匀顶光，光比 3:1，避免顶光死黑眼窝（略加前侧补）。
- **光比 3:1 ~ 6:1**：体育允许大光比，但**关键动作那一镜必须压回 4:1**，否则动作被暗部吃掉。

## 10. 色彩与质感

- **战队配色 / 赛道色是身份锚点**：红蓝对抗、跑道红、草坪绿、泳池蓝——色彩直接交代"谁对谁"。
- **运动模糊是速度的物理载体**：保留适度运动模糊（1/250–1/500 快门）才有冲力；过度平滑插帧会让冲刺变慢。
- **扬尘/水花/汗是现场感的来源**：空气里必须有东西飞溅。
- 调色：中高饱和 + 高对比（赛事转播感）；户外可偏自然，室内馆可偏冷净。
- 光圈 **f/4–f/5.6**：全景里的身法必须在焦内（浅景深是美食片语法，不是体育的）。

## 11. 升降格用法

| 瞬间 | 速度 | 效果 |
|---|---|---|
| 冲线 / 进球 / 落地 | 1/4（120fps） | 标志性重音，全片 1–2 个 |
| 击球接触 / 水花 | 1/8（240fps） | 微观爆点，常配 ECU |
| 腾空滞空 | 1/2（60fps） | 拉长滞空，制造"飞跃" |
| 竞速段 | **正常速度或轻微抽帧** | 升格会杀死竞速的密度感与实时感 |

**规则**：升格镜必须**前后夹常速镜**，孤立的慢动作等于卡顿/广告片。全片升格总时长 ≤ 20–25%。

---

## 12. 声音设计（比赛真实感的关键）

- **现场声必须落在切点上**：球鞋摩擦、球撞击、哨声、入水声、轮胎嘶鸣——声画同步是"有力"而非"表演"的根本。
- **观众席是隐形配角**：人浪欢呼、嘘声、主场呐喊，建立赛事真实感；蓄势段只留环境声（风、脚步、呼吸、器械）。
- **解说/数据与画面同步**：可选低频鼓点当节拍器，爆发段加密一击一点；升格镜留空或只给重击。
- **收束渐弱到欢呼声**：与"庆祝/终场"同步，而非静默切断。

## 13. 翻车点 ×7

1. **拍成 MV 不是比赛** → 只有炫技运动，毫无比分/攻防/计时推进，观众看完不知道谁赢。必须让每段落有**明确赛况结果**（进球/出界/抢断/名次变化）。
2. **慢镜过多丢实时感** → 升格占比过高、未夹常速，力量感消失变成"运动品牌形象片"。升格总时长 ≤ 20–25%，且必须夹常速镜。
3. **空场/穿帮** → 没给观众席或观众席穿帮（人数忽多忽少、空座明显），失去赛事真实感。修正：PRESERVE 保留观众席氛围；AVOID 空场/穿帮观众。
4. **计分板/计时器不可读** → 比分/计时是体育的"数据钩子"，模糊或乱跳会让观众失去锚点。修正：PRESERVE 计分板/计时器清晰可读且与赛况一致；AVOID 计分板模糊/数字乱跳。
5. **误用舞台综艺语法** → 套用"切点严格卡 BPM、舞者式摆拍"，运动员像在拍舞不像在打。体育的节奏来自**比赛流**（攻防/计时），不是音乐节拍。
6. **缺少转播机位认知** → 只用艺术化固定机位，观众不知"这是比赛"。修正：穿插转播式机位（中线俯拍/边线跟拍/篮下仰拍/终点急推）。
7. **跟拍丢主体/轴线乱** → 跟拍中主体忽大忽小、忽左忽右，观众失去方向。轴线写进 PRESERVE（如"进攻方恒画面左"），跟拍保持同速。

**附加**：不要写"燃的/精彩的/激烈的"这类主观词，模型无法执行；改写成物理描述（鞋钉入地、球皮形变、冲线瞬间胸膛撞线）。

## 14. 可借导演 / 摄影锚点（L3 点缀，只在末尾加一句）

- **体育转播 / 体育纪录片语法** — 动态跟拍 + 中线俯拍 + 慢放回放 + 数据叠加（计分板/计时器）。适合"真实赛事感"。
- **NFL Films 式电影感体育** — 中低饱和 + 颗粒 + 升格英雄镜 + 宏大场馆全景，把比赛拍出史诗感（注意升格占比仍 ≤25%）。
- **极限运动第一视角** — 叠加 `medium/action-cam.md`（GoPro/FPV 鱼眼、运动模糊、临场喘息声）。

**风格锚点片单**（可写进提示词做风格描述）

| 赛事/影片 | 特征 | 关键词 |
|---|---|---|
| 体育转播信号 | 中线俯拍+边线跟拍+慢放回放+计分板 | 实时、数据、转播机位 |
| 《最后的舞动》式体育纪录片 | 动态跟拍+升格英雄镜+颗粒 | 史诗感、纪实、慢镜重音 |
| 奥运田径转播 | 终点急推+1/4 升格+计时器 | 冲线、速度、数据 |
| 极限运动（X Games/冲浪） | FPV 第一视角+鱼眼广角 | 沉浸、临场、运动模糊 |

**⚠️ 不要与之叠加**：美食片式浅景深微距（f/2.8 让全景身法失焦）、MV 式卡拍摆拍（体育节奏来自比赛流不是 BPM）。

## 15. 中英双语锚点句（可直接贴进提示词）

**每镜四件套**（跟拍段落每一镜必须写全，缺一项模型就自由发挥）：

```
[时间戳] [景别]。[单一动作]。[单一运镜]。[切换方式 / 速度标记]
```
例：`3.2–3.9s：中景（MS）。白衣边线运球突破，防守者侧滑封堵。镜头侧向同速横移跟拍（lateral tracking）。常速。`

**中文**
> 低机位全景，场馆 5600K 硬光直打，看台 6500K 冷光混光；白衣（画面左）带球突进，黑衣（画面右）回防封堵，两人沿边线高速相持；镜头侧向同速横移跟拍，竞争关系清晰；空气中有扬尘与汗光，中高饱和高对比；球鞋摩擦声与观众欢呼落在切点上；计分板在画面边缘清晰可读，比分随攻防跳动。

**English**

## 17. 硬约束必须写成「更硬的否定指令」（实测教训）

无论哪类体育，H3 都会把精力放在构图与氛围上、把约束项按「美观优先」打折。**以下四项必须写成否定式的硬指令，不能只写宽松的正面描述**：

1. **实时感 / 少慢镜**：不能只说「有慢镜」。实测全片慢镜会变成广告片。加固：PRESERVE 改「保持常速比赛流 + 仅关键瞬间（冲线/进球/落地）升格，升格总时长 ≤ 20–25%」；AVOID 加「连续升格 / 全片慢镜使比赛变成品牌形象广告片」「升格镜未夹常速镜」。
2. **赛况推进**：不能只说「激烈的比赛」。实测会拍成无目标的炫技运动。加固：PRESERVE 加「每段落有明确攻防/得分/计时推进，比分或排名在变化」；AVOID 加「无目标的炫技运动（一群人跑但无进球/无计时推进/无对抗结果）」。
3. **观众 / 场地**：不能只说「有观众」。实测会出现空场或穿帮。加固：PRESERVE 加「保留观众席氛围与可读计分板/计时器」；AVOID 加「空场 / 穿帮观众 / 计分板模糊不可读 / 无赛事标识」。
4. **转播机位**：不能只说「机位多变」。实测会只用品味化固定机位丢失赛事感。加固：PRESERVE 加「穿插转播式机位（中线俯拍/边线跟拍/篮下仰拍/终点线急推）让观众认知这是比赛」；AVOID 加「仅用艺术化固定机位丢失赛事感」。

## 18. 提示词粒度：体育默认「详细逐镜头分镜」（实测结论）

对 MiniMax H3 这类阅读能力较强的模型，体育提示词也存在三档，但**实测只推荐一种**，且**不向用户提供「宽松 / 中档 / 详细」的选择**——默认直接写详细版：

| 粒度 | 写法 | 结果 |
|---|---|---|
| **详细（推荐 · 默认）** | 逐镜头分镜，时间戳精确到 0.1s，每镜写全「景别＋单一动作＋单一运镜＋切换方式/速度」四件套 | 赛况秩序最稳、硬约束被执行最彻底、**模型没空子偷懒**；代价是机位不如自由发挥灵动，但体育应优先"不出错" |
| 过宽 | 只给「燃、快节奏、精彩比赛」等形容词 + 硬约束 | 前 3 秒还在摆 pose、连续同角度群跑、比分不推进、结尾回归死定格 ❌ |
| 中档 | 场景级时间骨架 + 导演意图 + 硬约束 | 方向正确，但会在构图上打折硬约束（计分板模糊、观众穿帮、升格过多）❌ |

**结论：体育一律默认详细逐镜头分镜，不询问用户要宽松还是详细。** 形容词 H3 无法直接执行；不写分镜又会让它在构图与氛围上偷懒、把硬约束打折。详细版的机位偏执行感是可接受的代价。

## 19. 好看的动态收束（体育结尾不能突兀/死定格）

体育的结尾天然有**明确收束信号**——冲线瞬间、终场哨、进球庆祝、锁定胜局。用好它，不要突然切断或回归死定格：

- **明确写死收束信号**：如「冲线胸膛撞线 → 急推升格 → 全场观众起立欢呼，计分板定格最终比分」；或「终场哨响 → 球员相拥庆祝，观众人浪涌动」。
- **保留全场微动**：庆祝中人群、发带、草屑仍在动，不是死定格；这是"动态定格"而非"死定格"。
- **AVOID 难堪/突兀**：结尾禁「无信号突然黑屏」「主体定格成雕塑无反应」「计分板停留在错误比分」。
- 升格收束镜仍须夹常速镜（见 §11 规则），不要全片收尾连续慢镜。

## 附录 · 五级降级方案（模型糊了怎么办）

若出现闪烁、身份漂移、动作糊成一团，**按顺序降级，一次只退一级**：

1. **减镜数**：13 镜 → 9 镜，合并爆发段相邻两镜（保留景别跳跃，先删插入空镜）。
2. **去升格**：删掉所有 speed ramp 标记，全片常速（先保证实时感）。
3. **降景别跨度**：ECU 换成 CU，减少极端特写（模型在 ECU 上最容易崩脸/崩手）。
4. **拉长最短镜**：最短镜从 0.4s 提到 0.8s。
5. **最后手段**：退回 6–8 镜、每镜 1.2–2s 的稳妥版，牺牲快切换稳定（此时容易滑向 MV，须靠 §17 硬约束兜底赛况推进）。
