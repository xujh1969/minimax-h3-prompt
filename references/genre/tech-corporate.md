# 题材语法手册 · 科技宣传 / 企业形象 / 产品发布 Tech & Corporate

> **一句话定性**：科技片卖的不是"东西长什么样"，是**这套技术此刻正在运转，而且比人精确**。你的任务是让观众相信"它是真的，且已经在跑"。
> 所有决策都回到一个问题：**这个镜头里有东西在动吗？动的是机器，还是只有镜头？**

**它不是 product.md，也不是 scifi.md：**
产品片拍**静物陈列**（东西被摆好、被看），科幻片拍**不存在的幻想**（尺度与敬畏），
科技片拍的是第三类 —— **真实存在的技术 + 无人化洁净感 + 宏大叙事**。
判据：镜头里的东西如果**停下来就不成立**，那就是科技片。

**三条子路线，先选一条再动笔，混用必翻车：**

| 路线 | 硬科技工业 | 数字基建 | 消费科技发布 |
|---|---|---|---|
| 场景 | 产线、机械臂、焊装车间 | 数据中心、机柜、网络可视化 | 黑棚、聚光、产品悬浮 |
| 主色 | 冷蓝 + **暖钢橙**（火花/工件） | 纯冷蓝紫，单一色相 ≥ 85% | 中性灰白 + 单一强轮廓光 |
| 色温 | 环境 5600K / 暖破局 2800–3200K | 6500–7500K 单一冷源 | 5000–5600K 中性 |
| 光比 | 4:1 ~ 5:1 | 6:1 ~ 8:1，走廊大面积压黑 | 8:1 以上，背景纯黑不见边界 |
| ASL | 1.2–1.6s | 1.4–1.8s | 1.0–1.4s |
| 空气 | 有尘、油雾、焊接烟、火花 | 极清澈 + 微雾（只为承载指示灯光晕） | **无介质**，纯黑绒背景 |
| 运动主体 | 机械臂、传送带、夹爪 | 指示灯、风扇、光流 | 产品自身旋转/悬浮/展开 |
| 声音 | 伺服、气动泄压、金属咬合 | 风机低频 + 电子脉冲 | 极简单点音 + 大段静默 |
| 参考感觉 | 工业纪录片 + 广告级打光 | 冷、空、无人、纵深无限 | Apple 式发布会影像 |

## 1. 母题动词 ×5（点火器 — 灵感全在动词里，不在形容词里）

| 动词 | 物理含义 | 典型镜头 |
|---|---|---|
| **运转 Cycle** | 技术存在的唯一证据 | 机械臂按节拍重复轨迹、传送带匀速流过、风扇叶片旋转 |
| **装配 Assemble** | 两个物体精确合拢 | 零件咬合到位、卡扣闭合、螺丝拧入、模块滑入插槽 |
| **流动 Stream** | 数据/物料的可见路径 | 光沿光纤跑向纵深、产品在产线上连续通过、指示灯逐列点亮 |
| **校准 Align** | 精度可见化 | 激光十字对位、探针缓慢落点、机械爪微调 0.1mm |
| **点亮 Boot** | 系统上电 = 生命体征 | 屏幕由黑渐亮、指示灯阵列逐排点亮、背光从边缘扩散 |

**用法**：写提示词前先选 **2–3 个动词**当骨架。选不出来 = 这条片子只是"蓝色的漂亮空镜"。
"科技感的/未来的/智能的/高端大气"这类词对模型**只会触发廉价蓝色壁纸**，动词才能长出画面。

## 2. 灵感种子 ×3（具体到可直接拍）

1. **「凌晨四点的无人车间」** — 空无一人的产线，只有机械臂在按固定节拍工作，火花每 2 秒溅一次。镜头贴地缓慢横移穿过一排机架，前景机架不断划过遮挡画面。远处有一盏暖黄检修灯亮着 —— 全片唯一的暖色，证明这里属于人类。
2. **「指尖的最后一步」** — 前 8 秒全是机器：夹爪、传送、扫码、封装，没有任何人。最后 2 秒一只戴白手套的手伸进画面按下确认键，指示灯由冷蓝转暖白。**人只出现一次，出现在结尾，且只有手**。
3. **「一次上电」** — 黑暗的数据中心走廊，最深处一排指示灯先亮，然后光逐列向镜头奔跑过来，机柜轮廓随之从黑暗中被"点"出来。镜头静止不动，让光自己完成运镜。8 秒一个镜头。

## 3. 必备镜头清单（不拍就不像科技片）

| # | 镜头 | 要点 |
|---|---|---|
| 1 | **运转中的机构 CU** | 机械臂/夹爪/风扇在动，动作有明确起止点。**静止的机构 = 样板间，死的** |
| 2 | **指示灯阵列纵深** | 灯排向画面深处延伸并有闪烁差异，f/2.0 让远端灯化为光斑。空间感靠这个 |
| 3 | **精度 ECU** | 微距拍咬合面、触点、螺纹、焊点，看得见公差级细节。**可信度住在这里** |
| 4 | **贴屏 UI / 叠加图形** | UI 必须贴合屏幕表面或投在实体上，带反光、带视差、带 1–2 帧延迟 |
| 5 | **手部介入** | 只拍手：戴手套的手放入工件、指尖划过触屏、掌心托起模块。**人在掌控技术** |
| 6 | **宏观揭示 LS/ELS** | 后拉或上摇，把前面所有特写归位到一个完整空间。**这是"渐强"的兑现点** |
| 7 | *(硬科技可选)* **火花/焊弧/激光** | 全片唯一高亮暖源，同时充当破局暖色 |

## 4. 开场钩子 ×2（前 2 秒抓人）

- **A · 上电时序**：黑场 0.3s，先给一声干脆的电子 tick（< 60ms），指示灯逐个亮起把画面"点"出来。**让观众看见系统被唤醒**。
- **B · 认不出的局部**：极浅景深下的金属曲面或一片光斑，观众不知在看什么；第 2 秒机械臂横入画面，物件的身份与尺度同时成立。

---

## 5. 节奏 ASL 与结构曲线（关键词：**渐强**）

- **ASL 1.0–1.8s**。比产品片快（产品片 2s+ 要"注视"），比科幻慢（科幻 2.0–3.5s 要"敬畏"）。
- **节奏靠渐强，不靠快切**：从**局部特写堆叠**开始，逐步放大景别，最后用一个宏观全景揭示收口。
  镜头时长应**前短后长**：开头 0.8–1.2s 堆叠，结尾 2.0–2.5s 停住。
- **10s 结构曲线**：
  ```
  0–1.5s   上电钩子 / 不可辨识局部     2 镜，0.7s，ECU，快而密
  1.5–4s   机构运转堆叠（母题动词）    3 镜，0.8s，CU，逐镜放大
  4–6.5s   手部介入 + 贴屏 UI         2 镜，1.2s，MCU，唯一的人
  6.5–10s  宏观揭示（后拉/上摇/航拍）  1 镜，3.5s，LS→ELS，运动减速至停
  ```
- **总镜头数 10s ≤ 8 镜**。超过就成了"招商 PPT 片头"，技术细节全被冲掉。
- **结尾必须有 ≥ 1 个 ≥ 2.5s 的稳定镜**，让宏大叙事落地。开头快、结尾停 —— 这就是渐强。

---

## 6. 景别策略

**主战场是 ECU / CU / MCU，但结尾必须有 LS 或 ELS** —— 这与科幻恰好相反：
科幻先给大再给小（尺度先行），科技片**先给小再给大**（证据先行，结论后置）。

- 起手：ECU（触点/纹理/光斑），观众先"贴着技术"
- 中段：CU → MCU 逐级放大，每镜比上一镜**多露出一点环境**
- 收尾：LS 或 ELS，把整条产线/整个机房/整个舞台一次交代完
- **人在画面中永远是局部**：只出现手、手臂、背影或剪影，占画幅 < 1/4
- **禁止**：正面中近景拍人脸说话（那是企业访谈，不是科技影像）

## 7. 运镜偏好

| 推荐 | 英文 | 用途 |
|---|---|---|
| 匀速直线横移 | steady lateral dolly / linear track | 沿产线或机柜走廊平移，前景不断划过 |
| 缓慢推入 | slow push in | 从机构外围推到咬合点，建立注视 |
| 后拉揭示 | slow dolly out / pull back reveal | 结尾归位，从局部退回全景 |
| 上摇 | slow tilt up | 沿机柜或结构垂直读完高度 |
| 精确环绕 | controlled slow orbit, constant radius | 产品发布路线的核心运镜，半径必须恒定 |
| 静止 | locked-off static | 让机械臂/光流/指示灯成为唯一运动 |
| 低空恒速航拍 | steady low aerial glide | 厂区/机房外景，速度匀且慢 |

**禁用**：手持晃动、快速甩镜、无动机变焦、加速环绕、抖动模拟"震撼"、蹦跳式转场。
**理由**：科技的核心卖点是**精确**。镜头一抖，观众潜意识收到的信号是"这套系统不稳定"。
**机器的运动要有机械感（匀速、有节拍、有起止），镜头的运动要有轨道感（匀速、无加速度）** —— 两者都不能"随意"。

## 8. 光位与色温

- **核心光位：大面积柔光顶侧铺底 + 硬光边缘勾轮廓**。金属靠**边缘光**成立，靠正面光只会变成灰板。
- **蓝紫青是母语色，工作区间 4500–7500K**：硬科技 5600K、数字基建 6500–7500K、发布会 5000–5600K。
- **必须有一处暖色破局（2800–3200K）**：工程师手上的暖光、一盏暖黄指示灯/检修灯、焊弧、一条橙色警示带。
  **全冷 = 廉价科幻壁纸。** 暖色面积控制在画幅 **5%–15%**，多了变成"温情企业片"。
- 光比：硬科技 **4:1 ~ 5:1**；数字基建 **6:1 ~ 8:1**（走廊两侧压死到纯黑）；发布会 **8:1 以上**，背景无边界。
- **屏幕与指示灯是光源不是贴图**：显式写它照亮了手/机架/地面（underlit by screen glow, LED spill on the rack）。
- 微雾只用在数字基建，且只为**让指示灯有光晕与光柱**；硬科技可用油雾/焊烟；**发布会路线绝对不加雾**。
- **绝对禁止：全画面均匀平光**。一旦全亮，机器变塑料模型，机房变办公室。

---

## 9. 色彩与质感

- 调色倾向：**低饱和冷调 + 单一暖色重音**。蓝/青/紫占 80% 以上，暖色只作重音，不作面积。
- 金属质感三件套：**边缘高光 + 表面拉丝方向 + 微弱各向异性反射**。没有这三样，金属就是灰塑料。
- 质感：**高锐度 + 中浅景深**（f/2.0–f/4，焦段 35–100mm；微距段 f/2.8 配 100mm）。
  数字感优于胶片感，但可加 **极轻颗粒**避免画面"塑料干净"。发布会路线可完全无颗粒。
- **表面允许"用过"**：硬科技必须有油渍、划痕、工装夹具的磨光边缘 —— 全新光洁 = 渲染图。
  数字基建与发布会路线例外：**要求绝对洁净**，一粒灰尘都不该有，洁净本身是卖点。
- 玻璃与亚克力要写**双层反射**（表面反射 + 内部折射），这是"高精度制造"的视觉签名。

## 10. 升降格用法

| 瞬间 | 速度 | 效果 |
|---|---|---|
| 零件咬合 / 卡扣闭合 | 1/2 (60fps) | 看清机构逻辑，精密感直接来自这里 |
| 火花 / 焊弧飞溅 | 1/4 (120fps) | 暖色轨迹被拉长，成为画面唯一"燃烧物" |
| 产品悬浮旋转 | 1/2 (60fps) | 重量感，太快像玩具，太慢像广告 CG |
| 机械臂完整动作 | **正常速度** | 升格会毁掉节拍感，机械的美感在**准时**不在缓慢 |
| 传送带 / 产线流动 | **正常速度或 1.5× 加速** | 加速表达吞吐量，升格表达工艺，别搞反 |
| 指示灯逐列点亮 | **正常速度** | 上电时序是真实节拍，改速就假 |
| 长时段厂区外景 | **延时 timelapse** | 只用于开场或结尾，中段用会打断渐强 |

## 11. 声音设计（律动是科技片的半条命）

- **低频律动铺底（60–120Hz pulse）**，有固定 BPM（建议 90–110），全片不断。这是"系统在跑"的听觉证据。
- **机械运转的规律音**：伺服电机、气动泄压嘶声、金属咬合咔哒、风机白噪。**规律 = 可靠**，不规律的机械声等于故障。
- **电子脉冲音**必须**短、干、无混响（< 60ms）**。拖尾长的电子音听起来像 2010 年代的科技片头。
- 发布会路线：**声音极简 + 大段静默**，产品出现瞬间可以全部剥离只留一声单音。
- **绝对禁止：管弦乐煽情**（弦乐渐强、铜管齐鸣、合唱）。那是公益片和城市宣传片的语法，
  一旦出现，观众收到的信息从"这项技术在运转"变成"这家公司想感动我"。

## 12. 翻车点 ×4

1. **技术是"陈列"的** → 机械臂停着、屏幕不动、产线空转不流。**静止的科技 = 样板间**。修法：每个镜头至少写一个正在进行的机械动作（rotating, cycling, sliding into place）。
2. **全冷无暖** → 通篇蓝紫，变成廉价科幻壁纸。修法：加一处 2800–3200K 暖源，占画幅 5%–15%，最好落在手上。
3. **UI 漂在空气里** → 悬浮的蓝色六边形、发光地球、无来源的粒子线，是科技片头号翻车点。修法：UI 必须**贴合屏幕表面或投在实体上**，写明反光、视差、1–2 帧延迟（screen-space UI with reflections and parallax）。
4. **人露脸** → 立刻变成"精英摆拍"式企业宣传片。修法：只给手、手臂、背影、剪影，人存在的方式是**介入**，不是**出镜**。

**附加**：不要写"科技感十足/震撼/引领未来/赋能"这类词，模型无法执行；改写成物理描述（机械臂以 0.8 秒节拍重复轨迹、指示灯逐列点亮、边缘光勾出拉丝金属）。

## 13. 可借导演 ×2（L3 点缀，只在末尾加一句）

- **大卫·芬奇** — 精确到毫米的机位、冷调低饱和、几乎无手持的机械化运镜。**科技片"精确感"的默认答案**，尤其适合数字基建路线。
- **雷德利·斯科特** — 工业空间中的逆光光束、烟雾与蒸汽、实用主义机械的厚重感。适合硬科技工业路线的车间与产线。

**⚠️ 不要与之叠加**：迈克尔·贝式快切晃动与镜头光晕轰炸（精确感当场崩塌）、王家卫式抽帧手持（与轨道运镜直接冲突）、韦斯·安德森式高饱和平光对称（消灭金属边缘光与暗部）。

## 15. 母题卡 ×4（可自由组合进任何科技片）

| 卡名 | 描述 | 英文锚点 |
|---|---|---|
| **上电时序** | 指示灯或屏幕逐级点亮，系统被唤醒 | LEDs igniting column by column down the aisle |
| **精确咬合** | 两个零件在升格中合拢到位 | parts locking into place, 1/2 slow motion |
| **暖色破局** | 全冷画面中唯一的暖光源，通常在手上 | a single 3000K warm lamp against the cold blue |
