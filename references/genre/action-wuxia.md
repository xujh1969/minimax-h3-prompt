# 题材语法手册 · 动作 / 武侠 Action & Wuxia

> **覆盖范围**：武侠 / 徒手格斗 / 追车追逐 / 竞技对抗。
> **不覆盖战争** —— 战争片见 `war-military.md`，法则**恰好相反**：**武侠给足信息，战争剥夺信息**。武侠观众必须看清每一招与左右站位；战争观众必须和士兵一样茫然。

---

> ⚠️ **阅读提示**：本文件中出现的所有 "2s / 每镜 2 秒" 都是**反面教材或最后降级手段**，不是推荐参数。开头第 10 行与翻车点第 1 条在讲"为什么不能均匀 2s 切"；只有文末第 5 级降级方案才允许 1.5–2s 稳妥版（模型扛不住快切时的保底）。正确节奏见下方呼吸曲线（蓄势 1.0–2.5s、**爆发 0.4–0.9s**、重音 0.8–1.2s、亮相 1.2–2.0s）。

## 1. 一句话定性

> 动作片的"快"不来自平均速度，来自**镜头时长的落差**。均匀 2s 一切 = 监控回放。
> 所有决策回到一个问题：**这一招，观众看得见吗？** 看不见的招式等于没打。

| 症状 | 成因 | 观感 |
|---|---|---|
| 节奏机械 | 每镜等长，无强弱 | 像监控回放，不像电影 |
| 缺少爆发 | 没有 < 1s 的连切 | 打得再狠也"不快" |
| 景别扁平 | 全在中景/近景徘徊 | 看不清身法，也没有情绪冲击 |

## 2. 母题动词 ×5（点火器 — 灵感在动词里，不在形容词里）

| 动词 | 物理含义 | 典型镜头 |
|---|---|---|
| **劈 Slash** | 重力加速度 + 单向发力，走最短路径 | 上半程 WS 举刀，下半程 CU 刃过面门，动作中切 |
| **闪 Evade** | 以最小位移换取生存空间 | 低机位 MS，后仰下腰，刃锋掠过鼻尖数厘米 |
| **腾 Leap** | 垂直 Z 轴脱离地面，摆脱重力约束 | 仰拍 WS，踩竹梢弹起，镜头随之上摇 |
| **缠 Entangle** | 力的僵持，动能被锁死 | 贴身 MCU，两柄兵器交叉抵住，手臂颤抖 |
| **定 Freeze** | 动能瞬间归零，只剩余物在动 | 亮相 pose 静止，衣摆与尘埃继续下落 |

**用法**：动笔前先选 **2–3 个动词**当骨架。"凌厉的/激烈的/精彩的"对模型几乎无效，动词与物理量才有效。

## 3. 灵感种子 ×3（具体到可直接拍）

1. **「一叶落地」** — 开场 2.5s 全静：竹叶脱枝、缓慢飘落。叶尖触地的**同一帧**双方同时出手，接 4 个 0.5s 连切。用静止的长度换爆发的力度。
2. **「三招定生死」** — 全片只有三次交手，每次 ≤ 0.8s，中间用 1.5–2.0s 的对峙与呼吸填满。适合写实短兵路线（《绣春刀》质感）。
3. **「追不上的背影」** — 追逐母题：前景障碍物连续划过（栏杆、廊柱、车流），主体始终在画面同一侧、始终差半个身位。**障碍物的划过频率就是速度感本身**，比车速更重要。

## 4. 必备镜头清单（不拍就不像动作片）

| # | 镜头 | 要点 |
|---|---|---|
| 1 | **ELS 环境立威** | 剪影对峙 / 竹林山峦，交代空间与人物关系，也是"静"的来源 |
| 2 | **ECU 起手** | 出鞘、握拳、上膛、脚跟碾地。**给爆发一个视觉发令枪** |
| 3 | **WS 全景招式** | **港片黄金律：打斗必须有全景，观众要看得见全身招式。** 缺此镜 = 只剩晃动 |
| 4 | **升格重音镜** | 命中或险避的瞬间降到 1/4 速，0.8–1.2s |
| 5 | **插入空镜 0.2–0.4s** | 落叶、惊鸟、踩碎枯枝、剑穗甩动、水滴。给喘息，也掩盖动作衔接不畅 |
| 6 | **ECU 眼神 / 刃口** | 杀意与判断，是快切中的情绪支点 |
| 7 | **亮相定格** | 明确结束态，静止 1.2–2.0s |

## 5. 开场钩子 ×2（前 2 秒抓人）

- **A · 声音先行**：黑场或极浅景深中先给 0.3s 金属出鞘声 / 上膛声 / 骨节爆响，再切入 ECU。**听觉钩子比视觉更快。**
- **B · 静止对峙**：1.5–2.5s 一动不动的 ELS 剪影，只有风、尘、衣摆在动。观众被"什么时候开始"吊住。**静得越久，第一刀越响。**

## 6. 节奏 ASL 与结构曲线

### 呼吸曲线（四段式）

一段完整打斗（8–15s）按下面组织，**镜头时长必须不等**：

```
【蓄势】静 ──→【爆发】炸 ──→【重音】慢 ──→【爆发】炸 ──→【亮相】定
 1.0–2.5s/镜    0.4–0.9s/镜    0.8–1.2s/镜    0.4–0.9s/镜    1.2–2.0s/镜
```

| 段落 | 镜头时长 | 内容 | 运镜 |
|---|---|---|---|
| **蓄势** | 1.0–2.5s | 对峙、出鞘、呼吸、落叶。**必须静** | static / 极缓 push in |
| **爆发** | 0.4–0.9s | 一镜一击，绝不塞两个动作 | tracking / whip pan / static |
| **重音** | 0.8–1.2s | 升格慢镜，命中或险避的瞬间 | arc / slow tracking |
| **插入** | 0.2–0.4s | 空镜：落叶、惊鸟、碎枝、剑穗 | static |
| **亮相** | 1.2–2.0s | 定格 pose，明确结束态 | static（或极缓推入后停住） |

### ASL 参考落点

| 风格 | ASL | 备注 |
|---|---|---|
| 胡金铨《侠女》竹林战 | 0.3–0.5s | 极限值，用剪辑造"轻功" |
| 徐克 / 程小东 | ≈ 1.0s | 凌厉快切 + 甩镜 |
| 袁和平《卧虎藏龙》 | 1.5–2.5s | 重身法，镜头更长 |
| **推荐落点** | **0.7–1.0s** | 快而不糊 |

### 硬上限与静动对比

**镜头密度 ≤ 1.5 镜/秒（AI 生成硬约束）。** 10s → 最多 15 镜，建议 11–13 镜；超过模型会糊成闪烁。
**快感来自前面的慢。** 开场必须静（雾、落叶、呼吸、鸟鸣），结尾必须静（定格、尘落、声音渐弱）。中间越炸，两端越静，对比越强。**全程都快 = 全程都不快。**

### 时长拉伸与幕次叙事结构（12–15s 防灌水）

快节奏不等于无顺序。动作戏即使再快，整体情节也必须有**连续因果的叙事顺序，不能生硬拼接、不能跳跃**。当一段打斗需要拉到 12–15s 时，**绝不能用「把 8–10s 内容 + 结尾长定格」硬撑**——那正是 AI 生成最容易翻车的「定格灌水」。正确做法：

- **按幕次铺动作**：把总时长拆成若干等长幕（如 5 幕 × 3s），每幕给一个明确的情节推进（发现 → 首攻 → 连击 → 夹击 → 收束），幕与幕之间主体连续、动作因果承接。
- **每幕必须都有动作变化**，不允许某幕只是重复同一广角画面。
- **收束幕用「活态收束」替代死定格**：结尾 2–3s 让雨继续落、衣摆/发梢续动、倒地者手指或肩头轻微抽动、主体走入景深——画面保持活态，而不是冻住。
- **活态收束的 PRESERVE/AVOID 写法**：PRESERVE 加「收束时雨/衣摆/倒地者仍有微动，画面保持活态」；AVOID 加「同一广角画面重复超过 1 秒」「结尾用无微动的纯静态定格填充」「超过 1.5 秒无动作变化的画面（含空镜灌水）」。
- 升格重音、全景、轴线锁定等规则在长片里仍全程适用，不因时长拉长而放松。

### 提示词粒度：动作戏默认「详细逐镜头分镜」（实测结论）

对 MiniMax H3 这类阅读能力较强的模型，动作戏提示词存在三档写法，但**实测只推荐一种**，且**不向用户提供「宽松 / 中档 / 详细」的选择**——默认直接写详细版：

| 粒度 | 写法 | 结果 |
|---|---|---|
| **详细（推荐 · 默认）** | 逐镜头分镜，时间戳精确到 0.1s，每镜写全「景别＋单一动作＋单一运镜＋切换方式/速度」四件套（见 §7/§8） | 叙事秩序最稳、硬约束被执行得最彻底、**模型没有空子可偷懒**；代价是机位不如模型自由发挥时灵动，但动作戏应优先保证“不出错” |
| 过宽 | 只给「快节奏、拳拳到肉、5 幕结构」等形容词 + 硬约束 | 前 3 秒还在摆 pose、连续 6 秒同角度群殴、对手友军互打、因果混乱、结尾回归死定格 ❌ |
| 中档 | 场景级时间骨架 + 导演意图 + 硬约束 | 方向正确，但实测仍会在构图上打折硬约束（斧距变近、结尾站定 pose、中段锁一面墙中近景、背景对手观望）❌ |

**结论：动作戏一律默认详细逐镜头分镜，不询问用户要宽松还是详细。** 形容词（拳拳到肉、快节奏）H3 无法直接执行；不写分镜又会让它在构图与氛围上偷懒、把硬约束打折——模型需要明确知道「第几秒发生什么、用什么景别与运镜」，而不是「自由发挥」。详细版的机位偏执行感是可接受的代价：动作戏宁可用秩序换灵动，也不要用自由换翻车。

### 硬约束必须写成「更硬的否定指令」（实测教训）

无论用哪档粒度，H3 都会把精力放在构图与氛围上、把约束项按「美观优先」打折。**以下四项必须写成否定式的硬指令，不能只写宽松的正面描述**：

1. **斧刃安全距离**：不能只说「≥30cm」。实测中激战仍让斧头贴近身体。加固：PRESERVE 改「一臂距离（约 50cm），斧锋从身侧挥过须明显落空」；AVOID 加「斧刃擦过/贴近/进入白衣身周一臂范围」「武器接触身体」。
2. **活态收束**：不能只说「雨/衣摆续动」。实测仍以「白衣站定尸堆中」的静态英雄 pose 结尾。加固：PRESERVE 加「白衣不摆站定英雄 pose，而是转身缓步走入景深」；AVOID 加「结尾白衣站定摆 pose 或环视倒地者」。
3. **中段机位**：不能只说「机位多变」。实测把 5–6 秒锁在同一面墙前中近景。加固：明确「中段击倒须穿插高角俯拍/低角仰拍/OTS/ECU 命中点；禁止连续 3 秒以上同一面墙前中近景固定机位」。
4. **背景对手**：不能只说「对手主动攻击」。实测未交战背景黑衣持斧站立观望。加固：AVOID 加「背景黑衣持斧站立观望、未交战也不扑上」；PRESERVE 加「所有未交战黑衣必须正在扑上攻击或已被击倒」。

## 7. 景别策略：阶梯跳跃

| 缩写 | 名称 | 动作片用途 |
|---|---|---|
| ELS | 大远景 | 环境立威、剪影对峙、竹林/山峦/街道气势 |
| WS / LS | 全景 | **看清全身身法**（港片黄金律：打斗必须有全景，观众要看得见全身招式） |
| MS | 中景 | 攻防回合、兵器交击 |
| MCU | 近景 | 表情、杀意、判断 |
| CU | 特写 | 手腕、脚步、剑柄、握把 |
| ECU | 大特写 | 眼睛、剑刃、火星、血珠、汗 |

**铁律：相邻两镜的景别至少跳 2 级。** ✅ WS → ECU（冲击最强，经典）、ELS → MS；❌ MS → MCU（只差一级，观感像跳切/穿帮）、❌ 连续三镜都在 MS。

**经典景别序列模板**

```
ELS 立威 → ECU 出鞘 → WS 冲刺 → MS 交击 → ECU 剑刃 → WS 身法(升格)
→ CU 脚步 → MS 连击 → ECU 眼神 → OTS 直刺 → WS 反制 → MS 亮相定格
```

## 8. 运镜偏好：六大经典手法

| 手法 | 要点 | 写进提示词的措辞 |
|---|---|---|
| **1 动作中切** Cutting on action | 在动作**进行中**切，绝不在停顿处切。一刀劈下：上半程 WS，下半程 CU → 力量翻倍 | `硬切，接续上一镜未完成的下劈动作 / hard cut, continuing the same descending slash` |
| **2 升格重音** Speed ramp | 命中或险避瞬间降到 1/4 速，随即恢复常速。武侠标志性手法 | `慢动作（1/4 速）/ slow motion at 1/4 speed`，下一镜 `恢复常速 / back to normal speed` |
| **3 甩镜转场** Whip pan | 高速横摇的运动模糊做"隐形剪辑"，是快切的润滑剂 | `向右甩镜切换 / whip pan right into the next shot` |
| **4 插入空镜** Cutaway | 0.2–0.4s 落叶、惊鸟、碎枝、剑穗、水滴。每段爆发间插 1 个，**不要连插** | `0.3s 空镜：一片竹叶掠过画面 / 0.3s insert: a bamboo leaf drifts past` |
| **5 轴线锁死** 180° rule | **白衣恒在画面左，黑衣恒在右**。轴线一乱观众立刻失去方向感 | 见下方 PRESERVE 强制项 |
| **6 亮相定格** Tableau | 戏曲传统，最后一个 pose 定住，同时满足 H3"明确结束态" | `静止定格在 [具体姿态]，保持到结束 / hold the final pose, static` |

> **轴线必须写进 PRESERVE**：`全片保持画面左右站位不变 / keep screen direction consistent: White always on frame-left, Black on frame-right`

**机位要"落差"、忌死板**：动作戏的机位不能全程平视固定，也不能反复用「极缓推入 / 极缓拉远」把节奏拖垮。快切段落应以 **whip pan / snap zoom（急推）/ arc（绕弧）/ tracking（跟拍）/ 荷兰角（Dutch）/ OTS（过肩）** 制造机位与景别的落差；高角俯拍（ELS 立威）与低角仰拍（MS 力量感）交替使用。运动镜头之间必须夹静止镜（ECU 冲击帧天然静止）作参照，否则观众无锚点。

**禁用**：无动机变焦、全程手持乱晃（追逐段除外）、每镜都用运动镜头（运动镜头之间必须夹静止镜，否则观众无参照物）、反复「极缓推入 / 极缓拉远」造成拖沓（那是文戏慢镜的语法，不是动作快切的）。

## 9. 光位与色温

- **核心光位：逆光 / 侧逆光**。逆光是动作片**速度的物理来源** —— 只有逆光才能照亮扬尘、雨丝、汗珠与刀刃反光。
- **侧逆勾边（rim light）**：把人物从背景剥离，快切时观众靠边缘轮廓识别谁是谁。这是"看得清"的前提。
- **色温分场**：竹林日戏 **5600K 日光**（硬光穿枝叶，斑驳光斑 + 丁达尔光柱）；荒漠客栈 **5000–5600K** 高对比硬光，扬尘做散射；夜战火把 **约 2000K** 低位跳动暖光，投影在墙上放大晃动；夜城追逐 **3200K 钠灯 + 5600K 补光**混色，主体冷、环境暖。
- **光比 4:1 ~ 8:1**：动作片允许大光比，但**关键招式那一镜必须压回 4:1**，否则动作被暗部吃掉。

## 10. 色彩与质感

- **尘埃与飘落物是速度的物理载体**。空气里必须有东西：扬尘、竹叶、雨、雪、火星、碎纸、羽毛。空气干净 = 速度消失。
- 调色倾向：**中低饱和 + 高对比**。武侠可偏青绿（竹林）或土黄（荒漠）单色化；现代格斗/追车偏去饱和 + 冷调。
- 质感：动作段用 **1/48–1/96 快门**。快门越快（1/500 以上）动作越清晰但越"硬"、越像纪录片；保留适度运动模糊才有力量感。
- 光圈 **f/4–f/5.6**：景深要够，全景里的身法必须全在焦内（**浅景深是美食片的语法，不是动作片的**）。允许颗粒与轻微抽帧感，禁止过度平滑的插帧质感。

## 11. 升降格用法

| 瞬间 | 速度 | 效果 |
|---|---|---|
| 命中 / 险避 | 1/4（120fps） | 标志性重音，全片 1–2 个即可 |
| 腾跃滞空 | 1/2（60fps） | 拉长滞空时间，制造"轻功" |
| 火星 / 血珠 / 碎屑 | 1/8（240fps） | 微观爆点，常配 ECU |
| 扬尘散开 | 1/2 | 尘埃轨迹可见，速度被留在空气里 |
| 连击段 | **正常速度或轻微抽帧** | 升格会杀死连击的密度感 |

**规则**：升格镜必须**前后夹常速镜**，孤立的慢动作等于卡顿。全片升格总时长 ≤ 20%。

## 12. 声音设计（快切不乱的关键）

- **剑击金属声必须落在切点上**（cut on the clash）—— 声画同步是快切"有力"而非"混乱"的根本。写提示词时把音效绑到具体时间戳。
- **鼓点当节拍器**：低沉鼓点在**爆发段加密**，一击一点；重音镜（升格）时鼓点**留空**或只给一记重击。
- **升格镜留空**：慢镜配低频拉伸声 / 短暂静音，恢复常速时声音"炸"回来。
- 蓄势段只留环境声（风、竹叶摩擦、呼吸、鞘口摩擦）；结尾渐弱到只剩风声与呼吸，与"静"的收尾同步。

## 13. 翻车点 ×5

1. **均匀等长切** → 每镜 2s，节奏机械如监控回放。必须长短交错，落差就是节奏。
2. **没有全景** → 全程 MS/CU 晃动，观众不知道谁打谁、身法是什么。**必须有 WS。**
3. **轴线穿帮** → 左右站位在快切中翻转，观众瞬间失去方向感。轴线写进 PRESERVE。
4. **一镜塞两个动作** → 模型必然糊掉或做错顺序。**一镜一击**，多的拆成下一镜。
5. **因果链断点（相邻镜头故事线不接）** → 上一镜"汽车撞摩托"、下一镜凭空"撞亭子"：亭子从未建立、撞摩托的线被吞掉，观众瞬间出戏。相邻镜头必须主体连续（新物体须在上一镜先铺垫方位）+ 动作因果（上一条动作线必须交代去向）。这是 SKILL.md「镜头连贯性 / 因果链」硬规则在动作场景的重灾区，写分段前先排一条事件因果链再落笔。
6. **定格灌水 / 生硬拼接** → 把原本 8–10s 的内容硬拉到 12–15s，靠「结尾长定格 + 同一广角画面反复」或把不相关的镜头硬拼填充。观感像卡住或循环，叙事逻辑断裂。修正：按上方「时长拉伸与幕次叙事结构」拆幕次、铺连续因果，收束幕用活态微动替代死定格。
7. **木桩对手 / 受力缺失** → 对手原地平站等挨打、被击中后无受力反应地直挺倒下，观感像砍木头，毫无力道。修正：每个对手必须先**主动扑上 / 挥兵攻击**（自带攻击动机与动量，不是等在原地）；被击中后必须有明确**受力反应**（后仰 / 踉跄 / 旋转 / 抱痛处 / 双臂乱挥）才倒下，绝不能像木桩直挺塌掉。把「主动攻击 + 受力反应」写进 PRESERVE，把「木桩等挨打 / 无反应直挺倒地」写进 AVOID。这是「拳拳到肉」的关键——击倒要靠 ECU 命中点 + 快门硬边冲击帧 + 对手受力反应共同呈现，而非常速掠过。

**附加**：不要写"凌厉的/激烈的/招式精妙"这类主观词，模型无法执行；改写成物理描述（刃过面门、扬尘被劈开、脚跟碾地）。

## 附录 · 五级降级方案（模型糊了怎么办）

若出现闪烁、身份漂移、动作糊成一团，**按顺序降级，一次只退一级**：

1. **减镜数**：13 镜 → 9 镜，合并爆发段相邻两镜（保留景别跳跃，先删插入空镜）。
2. **去升格**：删掉所有 speed ramp 标记，全片常速。
3. **降景别跨度**：ECU 换成 CU，减少极端特写（模型在 ECU 上最容易崩脸）。
4. **拉长最短镜**：最短镜从 0.4s 提到 0.8s。
5. **最后手段**：退回 5–6 镜、每镜 1.5–2s 的稳妥版，牺牲快切换稳定。
