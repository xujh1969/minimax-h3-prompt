# 题材语法手册 · 时尚 / 美妆 / 服饰 Fashion & Beauty

> **一句话定性**：时尚片卖的不是"这件衣服好看"，是**身份认同的投射** —— 观众要在 10 秒内产生"穿上它我是谁"的幻觉。
> 所有决策都回到一个问题：**这个镜头让人想成为画面里的那个人吗？**
> 铁律先行：**模特的动势比脸重要，服装的廓形靠风机和运动展现** —— 静止站着的模特，衣服等于挂在衣架上。

---

## 1. 母题动词 ×5（点火器 — 灵感全在动词里，不在形容词里）

| 动词 | 物理含义 | 典型镜头 |
|---|---|---|
| **甩动 Whip** | 惯性 + 风 | 头发甩过面部、裙摆扬起、袖口翻飞、围巾抛出 |
| **转身 Pivot** | 廓形的形变 | 从正面到 3/4 到侧面，肩线与腰线连续变化 |
| **垂坠 Drape** | 面料自重 = 材质的证词 | 丝绸滑落肩膀、大衣落下、褶皱自然堆积 |
| **涂抹 Glide** | 膏体与皮肤的交互 | 口红划过唇面、粉底在皮肤上晕开、精华滴落铺展 |
| **凝视 Lock** | 态度与对峙 | 视线转向镜头并停住 0.8s，不笑 |

**用法**：写提示词前先选 **2–3 个动词**当骨架。选不出来 = 这条片子只是"拍了个好看的人"。
形容词（优雅的/高级的/迷人的）对模型**几乎无效**，动词才有效。

---

## 2. 灵感种子 ×3（具体到可直接拍）

1. **「风的雕塑」** — 全黑背景，两台风机以 45° 对吹，模特全片只做**一个动作**：抬手、转身。裙摆和长发在空中形成一个持续约 2 秒的立体形状，1/4 升格把它拉成"雕塑"。摄影机静止，让面料成为唯一的运动主体。
2. **「膏体的地质学」** — 1:1 极端微距，一支口红膏体被刀片斜切，切面纹理像地质剖面一样出现层次与光泽；随后膏体在皮肤上划出一道，1/8 升格看色料颗粒被压平、铺开、显色。全片没有脸。
3. **「六次转身」** — 定机位定光，模特站在同一位置连续换 6 套造型，每两套之间用一次快速甩镜（whip pan）遮挡完成"换装"。观众看到的是一镜到底的错觉，节奏完全压在鼓点上。

---

## 3. 必备镜头清单（不拍就不像时尚片）

| # | 镜头 | 要点 |
|---|---|---|
| 1 | **全身廓形镜 FS** | **服饰片唯一不可省略的镜头**。85mm 以上焦距、水平机位，交代肩线—腰线—下摆的完整轮廓 |
| 2 | **面料微距 ECU** | 织纹、亮片折射、丝绸的连续高光、羊绒的绒毛边缘。这是"贵不贵"的判据 |
| 3 | **走位跟拍 Tracking** | 侧向平行跟随步态。**步态是时尚片的心跳**，比任何摆拍都有说服力 |
| 4 | **面部 CU（美妆核心）** | 眼神光必须有，皮肤要见次表面散射（subsurface scattering）与油润高光 |
| 5 | **配饰细节 ECU** | 鞋跟、扣子、耳坠、指甲、腕表。细节镜是节奏的换气口 |
| 6 | **风机动态镜** | 头发/裙摆被吹起的 1–2 秒，1/4 升格。廓形只有在运动中才成立 |
| 7 | *(可选)* **镜面 / 多重构图** | 镜中镜、玻璃反射，制造"自我审视"的心理层 |

---

## 4. 开场钩子 ×2（前 2 秒抓人）

- **A · 材质先于人**：极端微距贴着面料纹理开场（观众不知道这是什么），镜头拉开或失焦转移，人才出现。**先给触感，后给身份**。
- **B · 空场 + 脚步声**：空荡的场景静止 1s，只有高跟鞋落地声由远及近，人走进画框。听觉建立存在感，视觉后到。

---

## 5. 节奏 ASL 与结构曲线

- **Fashion film ASL 0.8–1.4s**（比美食快，比动作片慢）；**美妆微距段落 ASL 1.5–2.2s**（质感需要停留）。
- **时尚片独有的剪辑法则：剪辑跟音乐，不跟动作。** 切点压在鼓点（beat-locked）上，哪怕动作没做完也切。这与美食/产品片"动作完成才切"完全相反 —— 这是时尚片"高级感"的节奏来源。
- **10s 结构曲线**：
  ```
  0–1.5s  钩子（面料微距 / 脚步入画）  1 镜，1.5s
  1.5–4s  廓形与走位                  2–3 镜，0.9s，含 1 个 FS 全身
  4–6.5s  细节与面料 ECU              2–3 镜，0.8s，压鼓点
  6.5–8.5s 风机高潮 / 甩发            1 镜，2.0s，1/4 升格
  8.5–10s 凝视定格                    1 镜，1.5s，正常速度，不笑
  ```
- **总镜头数 10s ≤ 9 镜**（可比美食片多，节奏本就更碎）。
- **升格占比**：2–3 个，只给"甩发 / 裙摆 / 粉末爆开 / 膏体涂抹"。**走路和凝视不要升格**，会失去力量与真实。

---

## 6. 景别策略

**FS / MS / CU / ECU 四级全用**，这是时尚片与其他题材最大的不同 —— 它既要卖整体（廓形），又要卖细节（材质与妆面）。

- 起手：ECU（材质钩子）或 FS（气场直给）
- 中段：FS ↔ MS ↔ CU 交替，每 2–3 镜插一个 ECU 细节做换气
- 收尾：CU 凝视 或 FS 定格
- **服饰片必须至少一个 FS**；**美妆片必须至少一个 ECU（唇/眼/皮肤）**。缺了对应那一级，卖点直接失效。
- **禁止**：ELS 大远景把人淹没在场景里（除非做"孤独感/建筑尺度"的概念片）
- 相邻景别建议跳 1–2 级，FS→ECU 的大跳跃在时尚片里是加分项，制造冲击

## 7. 运镜偏好

| 推荐 | 英文 | 用途 |
|---|---|---|
| 平行跟随 | parallel dolly track | 走位，步态的连续性 |
| 环绕 | slow arc / gimbal orbit | 廓形 360° 交代 |
| 升降 | crane up / descend | 从鞋到脸的一次完整"打量" |
| 快速甩镜 | whip pan | 转场、换装、压鼓点 |
| 缓慢推入 | slow push in | 凝视，收束情绪 |
| 静止 + 人动 | locked-off, subject moves | 让风机和面料成为唯一运动 |

**禁用**：无动机手持晃动（除非刻意做 90s grunge / 街拍风）、鱼眼、广角贴脸。
**焦距铁律**：**服装用 50–85mm，美妆微距用 100mm，绝对不用 24mm 以下拍人。** 广角会把腿拍短、脸拍宽、鼻子拍大 —— 观众未必知道原因，但会本能觉得"这不高级"。需要环境感就用 35mm 全身，别再往下走。

## 8. 光位与色温

- **服饰主光：蝴蝶光 / 美人碟位（beauty dish 或大柔光箱置于前上方 30–45°）**，或反其道用**单一硬光源（single hard source）**制造建筑式硬阴影 —— 二选一，不要混。
- **美妆主光：环形光 / 美人碟正面 + 双侧条形光补轮廓**。**眼神光（catchlight）必须存在**，没有眼神光的美妆特写等于死人脸。
- 光比：时尚编辑感 **2:1–3:1**（偏平，保留面料细节）；戏剧/香水感 **6:1–8:1**（大面积阴影）。**光比选择就是气质选择**。
- 色温：**5600K 中性**为默认；**3200K 暖**做复古 / 温柔 / 生活方式；**7000K+ 冷**做未来 / 冷酷 / 高街。
- **绝对禁止：底光（uplight）** —— 鬼片脸；**顶光硬打** —— 眼窝黑洞（raccoon eyes），妆面全废。
- 皮肤补光用**大面积柔光 + 银反光板**填眼下阴影，宁可平一点，也不要有硬阴影切过脸。

---

## 9. 色彩与质感

- 调色倾向：**低饱和高级灰 / 单色主导 + 一个撞色**。整体降饱和，只留一个强色（正红唇、宝蓝、荧光绿）跳出来。
- **肤色是唯一的调色基准线**：肤色偏绿 = 病态，偏洋红 = 廉价。所有创意调色都必须先保住肤色再谈风格。
- 景深：**f/2 – f/4，浅景深是加分项**（与产品片的 f/8 全清晰完全相反）。人物锐利、背景奶油化，制造"她被世界虚化包围"的主角感。
- **质感：胶片感在时尚里是加分项**。轻颗粒（fine grain）、柔和高光滚降（gentle highlight rolloff）、Kodak Portra 类的暖肤色倾向 —— 这与 3C 产品片"零颗粒"的要求完全相反。
- **皮肤必须保留 texture**：可见毛孔 + 油润 sheen + 细小绒毛。过度磨皮 = 塑料人偶 = 高端感归零。

## 10. 升降格用法

| 瞬间 | 速度 | 效果 |
|---|---|---|
| 甩发 / 转身发丝散开 | 1/4 (120fps) | 每一缕头发的独立轨迹 |
| 裙摆 / 大衣扬起 | 1/4 | 面料形成空中"雕塑" |
| 散粉 / 亮片 / 花瓣爆开 | 1/8 (240fps) | 颗粒悬停感，香水片标配 |
| 膏体涂抹显色 | 1/4 | 色料被压平铺开的过程 |
| 液体精华滴落 | 1/8 | 表面张力与折射 |
| 走路步态 | **正常速度或 1/2** | 全升格会丢掉力量与态度 |
| 凝视 / 对视 | **正常速度** | 升格会显得矫情 |

## 11. 声音设计（音乐即结构）

- **时尚片的音乐不是配乐，是骨架**。先定 BPM，再排镜头 —— 剪辑点 = 鼓点，这是与所有其他题材最根本的差异。
- Foley 清单：布料摩擦、高跟鞋落地、拉链、金属扣、膏体开盖"咔哒"、喷雾"嘶"、呼吸声。
- **美妆微距段落可以完全静音 + 单一 ASMR**（膏体切开、粉饼按压），做节奏对比。
- 人声：**少即是多**。一句气声独白比整段旁白更贵。
- **禁止**：用流行歌带歌词全程铺满 —— 歌词会抢走观众对画面的注意力，让片子降级成 MV。

## 12. 翻车点 ×4

1. **模特静止站着摆拍** → 衣服等于挂在衣架上，廓形完全不成立。必须有风机 / 转身 / 走位，让面料动起来。
2. **广角贴脸（24mm 以下）** → 面部与身材比例畸变，一秒变廉价。服装 50–85mm，美妆 100mm 微距。
3. **过度磨皮 / 皮肤零质感** → 塑料人偶感。提示词里必须显式写"visible skin texture and pores, natural sheen"。
4. **只拍脸不拍全身（服饰片）** → 这就成了肖像片，服装卖点缺失。至少一个 FS 交代廓形。

**附加**：不要写"优雅的/高级的/时尚的/迷人的"这类主观词，模型无法执行；改写成物理描述（风机吹起裙摆形成弧形轮廓、丝绸沿肩线滑落、肩线锋利、低饱和冷灰调）。

## 13. 可借导演 ×2（L3 点缀，只在末尾加一句）

- **尼古拉斯·温丁·雷弗恩** — 霓虹色块、正面对称、长时间静止凝视。适合冷酷香水 / 暗黑美妆 / 高街。
- **索菲亚·科波拉** — 窗边自然光、柔和过曝、少女私密感。适合轻奢、香水、生活方式类。
- **质感参照（不是导演，是标尺）**：Nowness 类短片的"极简一个动作 + 强材质微距"，Chanel 类 TVC 的"高预算柔光 + 单色控制" —— 用来对齐审美层级，不要抄具体分镜。

**⚠️ 不要与之叠加**：迈克尔·贝式快切爆炸炫光（毁掉"注视"，廓形来不及看清）、诺兰式宏大交叉剪辑（尺度错位）、芬奇式冷精密（会把人拍成产品，肤色发死）。

## 14. 中英双语锚点句（可直接贴进提示词）

**中文**
> 全黑无缝背景棚拍，模特身着丝质长裙，风机自 45° 侧向吹动裙摆与长发；前上方 40° 大柔光作主光，双侧条形光勾出肩线，光比约 3:1，色温 5600K，眼神光清晰；模特抬手转身，裙摆在空中展开成弧形轮廓，1/4 升格；85mm 长焦，f/2.8 浅景深，低饱和冷灰调，肤色中性不偏绿；皮肤保留毛孔与自然油润高光，画面带极细胶片颗粒。

**English**
> Studio shot on a seamless black background, model in a silk gown, wind machines blowing the hem and long hair from a 45° side angle; large soft key light at 40° upper front, twin strip lights rimming the shoulder line, lighting ratio approx 3:1, 5600K, clear catchlights in the eyes; the model raises an arm and pivots, the hem unfurling into an arc in mid-air, 1/4 slow motion; 85mm telephoto, f/2.8 shallow depth of field, desaturated cool-grey grade with neutral skin tones; visible skin texture and pores with natural sheen, subtle fine film grain.

## 15. 母题卡 ×4（可自由组合进任何时尚 / 美妆片）

## 16. 自检清单（生成前逐条过）

- [ ] 选了 2–3 个母题动词，不是靠形容词撑
- [ ] 模特**在动**（风机 / 转身 / 走位），不是静止摆拍
- [ ] 焦距写了 50–85mm（服装）或 100mm 微距（美妆），**没有**广角贴脸
- [ ] 有眼神光；**没有**底光、没有顶光硬打
- [ ] 显式写了皮肤质感（毛孔 / sheen），没有过度磨皮
- [ ] 肤色中性不偏绿不偏洋红，创意调色没有牺牲肤色
- [ ] 服饰片有 ≥1 个 FS 全身廓形；美妆片有 ≥1 个 ECU
- [ ] ASL 0.8–1.4s，10s 内 ≤ 9 镜，切点压在鼓点上
- [ ] 升格只给了甩发 / 裙摆 / 粉末 / 膏体，走路与凝视保持正常速度
- [ ] 音乐先定 BPM 且不用带歌词的流行歌铺满
