# 题材语法手册 · 汽车 / 机械 Automotive & Machinery

> **一句话定性**：汽车广告卖的不是"车"，是**掌控欲** —— 观众要的是"我握着方向盘"的代偿快感，不是"这台车参数好"。
> 所有决策都回到一个问题：**这个镜头让人想坐进去踩油门吗？**
> 两条铁律先行：**① 车不能停着拍**（静止的车 + 静止的机位 = 展厅照片）；**② 车漆需要连续光带 light strip 才有形体**（点光源打在车漆上只是一堆白点，等于没打）。

---

## 1. 母题动词 ×5（点火器 — 灵感全在动词里，不在形容词里）

| 动词 | 物理含义 | 典型镜头 |
|---|---|---|
| **掠过 Sweep** | 光沿曲面流动 | 长条光带从车头滑到车尾，高光在腰线上流动 |
| **咬合 Grip** | 抓地力 | 胎壁形变、悬挂压缩、碎石弹起、刹车盘发红 |
| **切入 Carve** | 重心转移 | 入弯时车身侧倾、方向盘反打、车头指向变化 |
| **咆哮 Surge** | 动力释放 | 排气跳动、涡轮泄压、加速时车身下蹲 |
| **啮合 Mesh** | 机械精密（机械题材核心） | 齿轮咬合、活塞往复、机械臂闭环、卡钳夹紧 |

**用法**：写提示词前先选 **2–3 个动词**当骨架。选不出来 = 这条片子只是"车的照片会动"。
形容词（炫酷的/强劲的/优雅的）对模型**几乎无效**，动词才有效。

## 2. 灵感种子 ×3（具体到可直接拍）

1. **「光带的形体扫描」** — 全暗棚，一条约 6m 的长条形柔光从车头缓慢滑向车尾，高光在腰线与轮拱上连续流动，车身形体被一段一段"画"出来。摄影机全程静止，**全片唯一的运动是光** —— 这是所有高端汽车棚拍的通行手法。
2. **「轮拱的三秒」** — 机位贴地约 15cm，长焦跟拍单个前轮入弯：胎壁形变、悬挂行程压缩、碎石从胎面弹起。1/4 升格。全片不给整车，只讲一个轮子 —— 观众反而更相信这台车能跑。
3. **「无人的城市」** — 凌晨 4:30 空城，刚洒过水的柏油路面，车灯是画面里唯一的光源，湿地把光签名拉成一条竖直长倒影。车从画面深处驶来，crane 从高位下降跟到车头，一镜到底。

## 3. 必备镜头清单（不拍就不像汽车片）

| # | 镜头 | 要点 |
|---|---|---|
| 1 | **Beauty Pass / 光带扫掠** | 暗棚 + 长条光带滑过车身。**这是车漆唯一的"活"法**，也是形体的唯一证据 |
| 2 | **贴地低机位跟拍** | 镜头离地 10–30cm 侧向平行跟随。**速度感的唯一可靠来源**，机位越低越快 |
| 3 | **轮胎 / 轮拱 CU** | 胎壁形变、悬挂压缩、碎石。抓地力必须有物理证据 |
| 4 | **座舱内视角** | 手握方向盘、换挡、仪表点亮、余光看向后视镜。掌控欲的落点 |
| 5 | **跟车追拍 Chase** | 追拍车侧向平行跟随，长焦压缩，背景横向拉成条纹 |
| 6 | **灯组 / 光签名 ECU** | DRL 逐段点亮、尾灯贯穿式流水。**光签名是现代汽车的"脸"** |
| 7 | *(可选)* **航拍下降 / 环绕** | 交代地景尺度，收尾用；机械题材换成"齿轮啮合微距" |

## 4. 开场钩子 ×2（前 2 秒抓人）

- **A · 声音先于光**：黑场 0.5s，只有点火声或涡轮泄压"嘶"的一声，随后光签名逐段点亮。**汽车片的听觉钩子比视觉更快**。
- **B · 局部误导**：极端 ECU 开场（刹车卡钳 / 进气口 / 碳纤维纹理），观众认不出这是什么；镜头拉开或摇出，整车才成立。

## 5. 节奏 ASL 与结构曲线

- **两种节奏，必须分段，绝对不能混着切**：
  - **品牌 / 形体段**：ASL **1.2–2.0s**。形体需要停留时间才被看清，快切会让车漆变成一堆闪光。
  - **性能 / 赛道段**：ASL **0.5–0.9s**。急促、碎、多角度轰炸。
  - 一支片子的正确做法是：**先慢（形体）→ 后快（性能）→ 收慢（英雄镜定格）**，节奏本身就是叙事。
- **10s 结构曲线**：
  ```
  0–2s   钩子（声音 + 光签名点亮）    1 镜，2.0s，机位静止
  2–4s   形体（光带扫掠 / 环绕）      1–2 镜，1.5s
  4–7s   性能（贴地跟拍 + 轮拱 + 座舱）3–4 镜，0.7s，含 1 个升格
  7–10s  英雄镜（湿路 / 地景 / 定格）  1–2 镜，2.0s，缓慢收住
  ```
- **总镜头数 10s ≤ 9 镜**（比美食片多，因为性能段本就该碎）。
- **升格占比**：1–2 个，只给"轮胎入弯 / 碎石水花 / 车门与机械展开"。

## 6. 景别策略

**ECU / CU / MS / FS / ELS 五级全用** —— **汽车是唯一需要全部五级的题材**：既要卖细节工艺（ECU），又要卖整车形体（FS），还要卖"这台车属于什么世界"（ELS 地景）。

- 起手：ECU（局部误导）或 ELS（空旷地景 + 一个小小的车）
- 中段：FS ↔ MS ↔ CU 交替，性能段大量 CU/ECU（轮胎、卡钳、手、仪表）
- 收尾：FS 英雄镜 或 ELS 远去
- **禁止**：中庸的水平 MS 定机位拍静止车 —— 这就是 4S 店展厅照片，是汽车片最致命的平庸
- 机位高度铁律：**低于轮心的机位让车显得强壮，高于腰线的机位让车显得廉价**。默认贴地或齐轮心

## 7. 运镜偏好

| 推荐 | 英文 | 用途 |
|---|---|---|
| 贴地低机位跟拍 | low-angle tracking, 15cm off ground | 速度感第一来源 |
| 侧向平行跟拍 | parallel tracking / chase car | 展示侧面线条与速度 |
| 环绕 | slow orbit / arc | **车静止时唯一可用的运镜** |
| 摇臂升降 | crane down / Russian arm | 从地景切入到车头，尺度转换 |
| 车载机位 | hood mount / wheel-arch rig | 主观速度、机械振动的真实感 |
| 航拍下降 | drone descend to roof | 收尾、交代环境 |

**禁用**：无动机手持、变焦推拉（zoom）、高机位俯拍静止车。
**运镜铁律**：**车静止时镜头必须动；车运动时镜头可以静止。任何一帧里，至少有一方在动。** 两边都静止 = 展厅照片，这是汽车片最常见也最不可原谅的失败。

## 8. 光位与色温

- **棚内核心光位：超长条形柔光带（light strip，越长越好）+ 顶部天幕（overhead silk / soft box 6m+）**。
  **车漆反射的是"光源的形状"** —— 它是一面弯曲的镜子。点光源打上去只得到一堆孤立白点，车身完全没有形体。**必须用有长度的连续光源**，才能在腰线上拉出一条从头到尾的高光带。
- **外景核心时段：黄金时刻（日出后 / 日落前 30–45 分钟）** 或 **蓝调时刻（日落后约 20 分钟窗口）**。
  蓝调时刻是**唯一能让车灯亮度与环境天光平衡**的窗口 —— 早了车灯看不见，晚了环境全黑没层次。这 20 分钟是汽车片最贵的 20 分钟。
- 色温：黄金时刻 **3000–4500K 暖**；蓝调时刻 **环境 7000–9000K 冷 + 车灯 3200K 暖**（冷暖对撞是蓝调镜的全部魅力）；棚内 **5600K 中性**。
- 光比：车漆 hero 镜 **6:1–10:1**（高对比才有形体）；环境镜 **3:1**。
- **绝对禁止：正午顶光（约 11:00–15:00）** —— 车顶死白、玻璃反出整片天空、车身毫无形体。**这是汽车片的"食堂顶光"**，等价于美食片的顶光平打。
- **洒水车是标配**：湿路面让所有灯光和车身在地面形成倒影，画面亮度层次立刻翻倍。**干燥的柏油路等于没打光**。

## 9. 色彩与质感

- 调色倾向：**冷调科技**（青蓝阴影 + 中性高光，适合电车 / 性能）或 **暖金奢华**（琥珀高光 + 暖阴影，适合旗舰 / 豪华）。**二选一，不要混** —— 混了就是"调色师没有观点"。
- 黑位要压实（crushed blacks），高光允许小面积过曝（车灯、金属反光），车漆要看得出 **clear coat 的透明层深度**，不是一块塑料色。
- 光圈：跟拍 / 座舱 **f/2.8–f/4**（浅景深，前景虚化制造速度）；英雄整车镜 **f/8**（整车清晰，不能虚掉车尾）。
- **焦距是汽车片的秘密武器：85–200mm 长焦压缩**。长焦让车显宽、显低趴，让背景横向流动成条纹 —— 速度感一半来自焦距而不是车速。**广角 14–24mm 只用于车载 rig**，手持广角绕车拍会把车拍成畸变玩具。
- 数字感 + **轻微 halation（车灯光晕）**，让灯组有"发烫"的物理感。

## 10. 升降格用法

| 瞬间 | 速度 | 效果 |
|---|---|---|
| 轮胎入弯 / 胎壁形变 | 1/4 (120fps) | 看见橡胶的形变与悬挂行程 |
| 碎石 / 水花 / 尘土爆开 | 1/8 (240fps) | 每一颗颗粒的独立轨迹 |
| 光带扫过车漆 | 1/2 (60fps) | 高光流动被拉长成绸缎感 |
| 车门 / 鸥翼门 / 机械展开 | 1/2 | 机构行程可见 = 精密感 |
| 齿轮啮合微距（机械） | 1/4 | 咬合瞬间的对位精度 |
| **直线加速 / 全油门** | **正常速度，或 1/1.5 轻微加速** | **升格会直接杀死速度感 —— 汽车片头号铁律** |

## 11. 声音设计（引擎要分层，不是一坨轰鸣）

- **引擎声必须分三层**：低频 rumble（进气与缸内）/ 中频 排气声浪 / 高频 涡轮泄压"嘶" + 换挡"咔"。混成一坨就是廉价音效库的味道。
- Foley 清单：轮胎摩擦、碎石打底盘、风噪、安全带扣入、**车门关闭那一声"咚"**（低频越厚，观众越觉得这车贵 —— 这是汽车行业公认的品质暗示）。
- **电车专用解法**：没有引擎声，就用 **sub-bass 低频铺底 + 静默**。**静默是电车片的武器** —— 城市噪音突然消失的那 1 秒，比任何声浪都有说服力。
- 音乐：性能段用强节拍（切点压鼓点），品牌 / 形体段用低频铺底，不要在形体段上强节奏。

## 12. 翻车点 ×4

1. **正午顶光拍外景** → 车顶死白、玻璃反天、车身无形体。只拍黄金时刻 / 蓝调时刻，或进暗棚。
2. **用点光源打车漆** → 车身上一堆孤立白点，形体完全丢失。必须写"连续长条光带 continuous light strip"。
3. **静止车 + 静止机位** → 4S 店展厅照片。车不动就让镜头 orbit，镜头不动就让车穿过画框，至少一方在动。
4. **加速段用升格** → 速度感归零，力量变成慢舞。加速必须正常速度甚至轻微加速；升格只留给轮胎、碎石、机械展开。

**附加**：干燥地面记得写"wet asphalt after rain"（洒水）。不要写"炫酷的/强劲的/极致性能"这类主观词，模型无法执行；改写成物理描述（车身入弯侧倾、悬挂压缩、碎石从胎面弹起、腰线上一条连续高光带）。

## 13. 可借导演 ×2（L3 点缀，只在末尾加一句）

- **迈克尔·贝** — 贴地仰拍 + 环绕 + 逆光炫光 + 高对比。适合性能车 / 肌肉车 / 改装文化。
- **丹尼斯·维伦纽夫** — 空旷地景、巨物尺度、极简构图与低饱和。适合电车 / 概念车 / 未来出行叙事。
- **行业通行参照（不是导演，是标尺）**：BMW《The Hire》系列奠定的"车即角色 + 真实驾驶"叙事；德系品牌棚拍片长年通行的"暗棚 + 超长光带扫掠"形体手法。对齐质感即可，不要抄具体分镜。

**⚠️ 不要与之叠加**：韦斯·安德森的正面对称糖果色（车会变成玩具模型）、王家卫的手持抽帧霓虹（车身线条与形体全部丢失）、美食片的暖调柔光小景别（尺度感完全错位）。

## 14. 中英双语锚点句（可直接贴进提示词）

**中文**
> 蓝调时刻的空城街道，柏油路面刚洒过水形成镜面倒影；一台深色轿跑从画面深处驶来，贯穿式尾灯与 DRL 是画面主要光源，环境色温约 8000K 冷蓝、车灯约 3200K 暖，冷暖对撞；摄影机贴地约 20cm 侧向平行跟拍，135mm 长焦压缩，背景横向拉成流动条纹，f/2.8；车身腰线上有一条连续高光带随行进流动，光比约 8:1，黑位压实，车灯带轻微 halation 光晕；正常速度，不使用升格。

**English**
> Empty city street at blue hour, freshly wetted asphalt forming mirror reflections; a dark coupe approaches from deep in frame, its full-width tail bar and DRL signature as the primary light sources, ambient around 8000K cool blue against 3200K warm headlights; camera tracks parallel at roughly 20cm off the ground, 135mm telephoto compression, background smeared into horizontal streaks, f/2.8; a continuous specular highlight strip runs along the beltline as the car moves, lighting ratio approx 8:1, crushed blacks, subtle halation around the lamps; real time, no slow motion.

## 16. 自检清单（生成前逐条过）
