# 题材语法手册 · 产品 / 静物 / 3C数码 / 电商 Product & Still Life

> **一句话定性**：产品广告卖的不是"功能"，是**触感的预演**。你的任务是让观众的手指发痒，想伸手去摸、去按、去掰开它。
> 所有决策都回到一个问题：**这个镜头让人想上手吗？**
> 铁律先行：**倒影与边缘高光是质感的唯一来源** —— 产品本身不发光，观众看到的"高级"，全部是光源在它表面的反射形状。

---

## 1. 母题动词 ×5（点火器 — 灵感全在动词里，不在形容词里）

| 动词 | 物理含义 | 典型镜头 |
|---|---|---|
| **掠过 Sweep** | 光在表面流动 | 窄光带从产品一端扫到另一端，高光沿倒角滑行 |
| **旋转 Revolve** | 形体的完整交代 | 转台自转 / 镜头环绕，轮廓线连续变化 |
| **开合 Unfold** | 结构与工艺 | 翻盖、抽出、弹出、铰链展开、磁吸吸附 |
| **悬浮 Levitate** | 脱离重力与场景 | 产品无支撑漂浮、缓慢自旋、部件环绕 |
| **拆解 Explode** | 内部真相 | 部件沿轴线分离、悬停、再归位 |

**用法**：写提示词前先选 **2–3 个动词**当骨架。选不出来 = 这条片子只是"把产品放着拍"。
形容词（高级的/精致的/科技感的）对模型**几乎无效**，动词才有效。

---

## 2. 灵感种子 ×3（具体到可直接拍）

1. **「一道光的巡航」** — 全黑背景，产品本体几乎不亮，只有一条 2° 窄光带从机身一端极缓地扫到另一端。观众看到的不是产品，是**高光在 CNC 倒角上流动的那条线**。摄影机全程静止，全片唯一的运动是光。
2. **「磁吸归位」** — 三个部件从画面外飞入，在距主体约 3cm 处急停悬浮 0.5s，然后"咔哒"一声同时吸附归位。1/4 升格拍飞入，**归位瞬间切回正常速度**——速度的落差就是"精密"的听觉与视觉证明。
3. **「材质接力」** — 一镜到底的微距贴面横移：阳极氧化铝的细磨砂 → 抛光倒角的一道刺目高光 → 玻璃的深度反射 → 皮革的毛孔。不切镜、不换光，靠材质自己的反光差异完成叙事。

## 3. 必备镜头清单（不拍就不像产品片）

| # | 镜头 | 要点 |
|---|---|---|
| 1 | **黑底英雄镜 Hero Shot** | 双侧条形光勾边，背景纯黑无杂物。**边缘那两条高光就是产品的轮廓线** |
| 2 | **光带扫掠 Light Sweep** | 窄光带划过表面，1/2 升格。这是硬表面材质的唯一"活"法 |
| 3 | **微距材质贴面** | 贴着表面横移，展示磨砂颗粒 / 倒角 / 编织纹 / 玻璃层次 |
| 4 | **功能演示** | 按压、翻开、插拔、旋钮转动。**手是尺度参照，也是"可用"的承诺** |
| 5 | **环绕 / 转台 360°** | 交代完整形体，f/8 全身清晰，一圈不超过 4s |
| 6 | **倒影镜** | 黑亚克力台面，倒影长度约主体的 1/3。倒影 = 高级感的低成本捷径 |
| 7 | *(可选)* **爆炸图 Exploded View** | 部件分离悬停，适合讲"内部工艺/堆叠" |

## 4. 开场钩子 ×2（前 2 秒抓人）

- **A · 光先于物**：全黑画面，一道高光沿看不见的轮廓划过 0.4s，观众先看到"形状"再看到产品。**先给轮廓，后给身份**。
- **B · 尺度错乱**：极端微距开场（1:1 以上），观众认不出这是什么 —— 是山脊？是电路？镜头拉开，原来是一枚按键的倒角。

---

## 5. 节奏 ASL 与结构曲线

- **两套逻辑，必须先选一套，绝不能混**：
  - **品牌 TVC**：ASL **1.2–2.0s**，重"注视"，留白多，一个镜头讲一件事。
  - **电商主图 / 详情页视频**：ASL **0.6–1.0s**，重"信息密度"，每镜必须回答一个购买疑问（多大？什么材质？怎么用？）。
- **10s 结构曲线（品牌 TVC 版）**：
  ```
  0–2s   钩子（光划过 / 极端微距）   1 镜，2.0s，机位静止
  2–4.5s 材质微距 ×2                2 镜，1.2s，含 1 个光带扫掠
  4.5–7s 功能动作（开合/按压/吸附）  2 镜，1.2s，含 1 个升格
  7–10s  英雄镜环绕 + 定格           1 镜，3.0s，缓慢 orbit 后停住
  ```
- **总镜头数 10s ≤ 8 镜**（电商版可放宽到 12 镜，但每镜必须有信息增量）。
- **升格占比**：1–2 个，只给"光带扫掠 / 部件飞入 / 液体粉末撞击"。**旋转和开合不要升格**，会显得机构松垮无阻尼。

## 6. 景别策略

**主战场是 ECU / CU / MS 三级**，但与美食片有一条关键差异：**产品片必须至少有一个能看清完整形体的 MS 或 FS**。看不清全貌的产品片，客户一定退回。

- 起手：ECU（细节钩子）或 MS（直接给全貌，电商逻辑常用）
- 中段：ECU ↔ CU 交替做材质，中间插 1 个 MS 回锚
- 收尾：MS 英雄镜（完整形体 + 品牌形象）
- **禁止**：ELS 大远景（产品会消失在场景里），除非是"场景植入"类生活方式片
- 相邻景别建议跳 1–2 级，避免 CU→CU 的"原地踏步"（这点与美食片相反，美食可以连续 CU）

## 7. 运镜偏好

| 推荐 | 英文 | 用途 |
|---|---|---|
| 缓慢环绕 | slow orbit / arc | 英雄镜，交代形体连续性 |
| 转台自转 | turntable rotation | 360° 展示，机位静止 |
| 微距贴面横移 | macro lateral slide | 材质与工艺 |
| 缓慢推入 | slow push in | 建立注视、收尾定格 |
| 视差升降 | parallax rise / descend | 让背景与主体分离，制造纵深 |
| 完全静止 | locked-off static | 让"光带"或"部件飞入"成为唯一运动 |

**禁用**：手持晃动、快速甩镜、变焦推拉（zoom in/out）、鱼眼广角。
**理由**：产品的卖点是**线条的准确性**。手持会让直线抖，变焦会在推拉过程中改变透视比例 —— 观众说不出哪里怪，但会觉得"这个产品不贵"。移动用 dolly/orbit，不用 zoom。

## 8. 光位与色温

- **核心光位：大面积柔光 + 长条形窄光（large softbox overhead + strip softbox 双侧）**。
  **硬表面产品反射的是"光源的形状"，不是"光源的亮度"** —— 点光源打在金属上只会得到一个白点，废掉。必须用**有长度的条形光**才能沿倒角形成一条连续高光。
- **色温 5000–5600K 中性为基准**；科技/数码可推到 **6000–6500K 偏冷**（冷 = 精密 = 理性）。
  **注意：这与美食片完全相反** —— 美食禁冷调，3C 欢迎冷调。
- 光比 **4:1 ~ 8:1**（黑底高对比出形体）；白底电商图反过来压到 **2:1**（均匀、无死角、无戏剧性）。
- 背景压暗 **3 档以上**，或用纯黑绒布 / 无缝背景纸。
- **绝对禁止：正面平打（on-axis flat light）** —— 边缘高光全部消失，产品瞬间变成"淘宝白底图"，无体积、无质感。
- **高反光表面必须围帐（light tent / 白卡围拢）**：否则灯架、天花板、摄影师会清清楚楚拍进产品倒影里。

---

## 9. 色彩与质感

- 调色倾向：**单色主导（monochrome）+ 一个品牌强调色**。深灰 / 纯黑 / 冷银是安全底色，饱和度整体压低，只让品牌色跳出来。
- **景深铁律：f/5.6 – f/11，产品必须从头到尾清晰**。这是与美食片最大的分歧 —— 美食用 f/2.8 奶油背景，产品前后糊掉会被客户直接否掉。需要极浅景深的只有"材质微距"单镜。
- 微距景深不够时用 **focus stacking（焦点堆栈）** 思路描述："整体锐利、无虚焦区域"。
- 质感：**零颗粒、高微反差、干净数字感**。胶片颗粒在 3C 品类是减分项（显得旧）。
- 表面状态：**干净、无指纹、无灰尘**。与美食"必须湿"相反 —— 产品必须**绝对干净**，除非刻意拍防水/户外场景才加水珠。

---

## 10. 升降格用法

| 瞬间 | 速度 | 效果 |
|---|---|---|
| 光带扫过表面 | 1/2 (60fps) | 高光流动被拉长成"绸缎感" |
| 部件飞入 / 磁吸归位 | 1/4 (120fps) 飞入 + **正常速度落定** | 速度落差 = 精密与阻尼感 |
| 粉末 / 水花 / 咖啡豆撞击 | 1/8 (240fps) | 看见颗粒的独立轨迹 |
| 翻盖 / 铰链展开 | 1/2 | 机构行程可见，工艺证明 |
| 转台旋转 | **正常速度** | 升格旋转会显得呆滞、失重 |
| 按键按压回弹 | 1/4 | 回弹的那一下就是"手感" |

## 11. 声音设计（留白比音效更贵）

- **极简主义**：产品片的声音总量应该很少。**大段静默 + 一个精准的 impact**，比铺满音效高级十倍。
- 核心音效清单：磁吸"咔哒"、金属轻敲、按键回弹、拉链、开盖泄气、低频 whoosh（转场）、UI 提示音。
- **音乐进入点**：通常在英雄镜出现时才进，或全片只有低频铺底（sub-bass pad）+ 音效。
- 立体声：部件从左飞入就把音效放左，环绕镜头让声场跟着转。
- **禁止**：全程节奏感强烈的电子乐盖住所有音效 —— 那是电商促销片的做法，会把品牌片拉低一个档次。

## 12. 翻车点 ×4

1. **正面平打** → 边缘高光归零，产品变白底图，无体积。必须用双侧条形光 + 顶部柔光。
2. **用点光源打硬表面** → 车漆式的"一堆白点"。光源必须有长度（strip / 天幕），才能形成连续高光带。
3. **浅景深 f/1.8 拍整机** → 前后糊，客户必退。整机镜头 f/5.6–f/11，只有材质微距才允许浅景深。
4. **高反光表面没围帐** → 灯架、天花板、摄影师全被拍进倒影。提示词里显式写 "clean seamless background, no reflections of the studio"。

**附加**：不要写"高级的/精致的/科技感的/极简的"这类主观词，模型无法执行；改写成物理描述（连续高光带沿倒角滑行、纯黑无缝背景、阳极氧化磨砂颗粒可见）。屏幕内容不要指望模型拍准，UI 一律按"后期合成"处理，提示词里写"屏幕关闭 / screen off"最安全。

## 13. 可借导演 ×2（L3 点缀，只在末尾加一句）

- **雷德利·斯科特** — 烟雾中的光束、仪式感极强的产品英雄镜。适合"发布会级别"的旗舰产品揭幕。
- **大卫·芬奇** — 精密对称、冷调、零随机的机械式运动。**他的冷精密在美食片是毒药，在 3C 片是刚需**。

**⚠️ 不要与之叠加**：韦斯·安德森的正面对称糖果色（会把旗舰机变成玩具）、王家卫的手持抽帧霓虹（丢失线条准确性）、迈克尔·贝的快切炫光（产品来不及被看清）。
