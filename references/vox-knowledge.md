# Vox 风格知识性视频 Playbook（H3 适配版）

> 本文件吸收自 voxeasy（VoxEasy 4.13）的「Vox 风格知识/科普视频」技法，已转译为 MiniMax H3 提示词写法。
> 它**只补充「知识性 Vox 视频」这一正交维度**，与题材层、画风层、动画原则层互不冲突，按「题材 → 结构 → 视觉 → 本层」顺序叠加加载。
> 触发词：Vox 风 / 剪纸拼贴 / 知识视频 / 科普 / 数据对比 / 信息图 / 新闻时间线 / explainer / 把一段文案做成短视频。
> 本文档与 `references/visual-style.md` 第 14 节「剪纸/皮影」配合：第 14 节给纸艺基底，本文件给**知识视频的结构与数据表达**。

---

## 一、何时走这一层

- 用户要把「一段知识/科普/数据/新闻文案」做成一个**风格统一、信息可读、无声或轻旁白**的短视频。
- 用户点名「Vox 风 / 剪纸拼贴 / 数据信息图」画风。
- 典型产物：科普讲解、数据对比、产品机制拆解、新闻时间线。
- 非目标：纯剧情短片、真人实拍、单图人像动效（那些走常规题材层 + ①/② 模式）。

---

## 二、Vox 视觉引擎核心（写进 `integrated_multimodal_description:` 首段的基底）

把以下内容有机写成一段自然英文，**不使用模板标签**：

1. **纸质基底 + 内容场景载体**：先确定本镜的内容场景载体（真实过程/界面/地图/图表/桌面/工作台/空间环境），再用 Vox 纸艺语言铺满画布。背景**必须有语义功能**（承载场景、尺度、路径、数据底板、工作空间或隐喻装置），禁止空白背景上的单张漂浮卡片，也禁止与内容无关的满屏彩色碎纸。
2. **扁平实体表达**：把主体转译为 `stylized minimal flat solid-color paper cutout sticker`。明确可见纸层厚度、切边和投影；禁止照片写实、光滑 3D、写实手部与说话人物。
3. **叙事演进**：用时间戳完成一次「建立 → 转变」，保持流体延时动画与纸质定格触感。
4. **原生质感**：锐利投影、明显纸层堆叠、高反差、干净矢量细节。

**品牌色不必每镜全部出现**：优先让主体和场景一眼可读，再用 1–2 种强调色做标签、箭头、圈选、路径或关键变化。

### 默认 Vox 调色板（Hex 仅作不可见生成控制）

- 暖珊瑚红 `#E8625C`、哑光青蓝 `#2B697A`、芥末琥珀黄 `#E5A93C`、奶油纸白 `#FAF9F5`、深炭灰 `#2D2D2D`、赤陶红 `#C05646`。
- 仅转译本镜场景的纸层、地面、墙面、桌面、图表底板、路径、圈选或强调区域，**不作为无意义碎纸装饰**。
- 预设配色方案见文末「八、知识类画风预设」。

## 三、表达方式路由（direct / story / metaphor）

每个内容镜头按以下顺序判断，**只选一种主要模式**。先定表达方式，再套 Vox 视觉转译；画风不得反过来改变表达方式。

| 模式 | 判定 | 画面要求 |
|---|---|---|
| `direct` 直接呈现 | 存在可直接看见的主体、场景、过程、操作、地图、数据或因果变化 | 以真实可识别对象/过程为中心（产品部件、设备、自然现象、地图变化、图表增长、具体操作）。画面必须**证明字幕中的事实**，不只做主题装饰。保留关键结构、数量、方向、尺度关系和变化逻辑。 |
| `story` 故事场景 | 没有自然过程足以讲清，但存在具体人物、地点和事件 | 一个镜头只讲一个小事件：人物目标、一个主要行动、一个结果。写清人物/地点/时代/环境/道具/空间关系；人物不能只是站立说明。同一镜头内保持身份/服装/道具/场景连续。 |
| `metaphor` 视觉隐喻 | 内容是总结、抽象关系、不可见机制或缺少清晰现实载体 | 先写唯一映射（如「API 权限 → 上锁的门」「信息阻塞 → 被截断的道路」）。隐喻必须成为可见主体/道具/空间关系，不能只写抽象气氛。映射从首帧到末帧保持不变；同一实体只可移动/开合/折叠/组装/连续形变。 |

- 能用真实主体、过程、人物行动或数据图形讲清楚时，**不强行添加门、钥匙、桥、工作台、卡片或仪表盘**。
- 只有核心关系本身不可见时，才进入隐喻模式。

## 四、叙事弧架构（整条视频的镜头角色）

所有架构都以**独立的镜头 01 标题镜**开场：只显示用户确认的完整标题，无旁白；标题镜的画面、动作、运镜由所选画风决定。Shot 数量不是强制值，优先服从用户确认的字幕边界与吸附时长，不得为套模板拆散完整含义或增加空镜头。

| 弧 | 适用 | 镜头链（01 为标题） |
|---|---|---|
| `pas` 痛点—激化—解决 | 产品发布、技术突破、效率工具 | 02 痛点/阻力 → 03 复杂度/损失加深 → 04 突破点/产品揭示 → 05 核心能力/解决过程 → 06 最终价值/结论 |
| `how_it_works` 机制拆解 | 科技科普、算法原理、系统机制 | 02 问题/外部现象 → 03 关键组成 → 04 差异/成本/规格比较 → 05 工作流程 → 06 综合结论/影响 |
| `timeline` 历史与演进 | 重大事件、地缘、历史发展 | 02 当前钩子/关键事实 → 03 起源 → 04 机制/转折 → 05 力量/资源比较 → 06 升级/扩散 → 07 网络/多方关系 → 08 回应/后果 → 09 未来判断 |
| `man_in_hole` 困境—突围 | 商业战局、品牌翻盘、危机突围 | 02 危机出现 → 03 困境加深 → 04 转折决策 → 05 执行/反弹 → 06 结果与经验 |

**字段映射（H3）**：每条弧的镜头 → 一个 `[Shot n]`（标题镜写 `[Shot 1]`，其余依次顺延）；每个 `[Shot n]` 内只承载该镜头的核心信息与一种表达方式。

## 五、数据视觉层（从镜头 02 起主动加 1–2 种信息元素）

- **大号冲击数字**：百分比、倍数、金额、年份或关键计数。
- **剪纸信息图**：柱状图、饼图、折线图、进度条或对比尺度。
- **标注系统**：红色圈选、箭头、虚线、括号或标签连接。
- **来源贴纸**：已验证来源的简短名称和年份。
- **时间线标记**：年份节点、里程碑或前后变化。

规则：
- 镜头 02 以后**关闭大标题**，只显示视觉确认阶段批准的短数据贴纸、来源和标签，不自动生成字幕全文。
- 一个中心主体，辅助元素最多三组；写清数量、形状、材质、颜色、Hex、方向、位置和状态。
- 数据约束：**所有数字必须有来源或由用户提供**；比较双方使用同一统计口径；每个镜头最多突出一个主结论和三组数字（数据类档案 `data` 的硬约束）。

## 六、固定运镜序列（Vox 专属，写进 `integrated_multimodal_description:`）

相邻镜头不使用相同运镜方向。沿用 Vox 顺序，运镜从头到尾连续执行，服务于主体/过程/故事/隐喻揭示，**不作为额外动作**：

- Shot 01：`push_in`（轻推入）— 标题冲击
- Shot 02：`tracking_pan_down`（随轨下摇）或 `pan_right`（右摇）
- Shot 03：`layer_dissection`（纸层解剖/分层展开）
- Shot 04：`balance_tilt`（平衡倾斜）
- Shot 05 起轮换：`pull_out`（拉出）/ `parallax`（视差）/ `static`（静止，只用于落幕点题）

---

## 七、构图纪律与动作分段

**构图纪律**
- 画面必须铺满全画幅，具有前/中/后景纸层；背景必须有语义功能。
- 背景复杂度克制：选 1 个主背景场景载体 + 最多 2 组辅助背景层；使用大面积、清晰边界、稳定层次，**不能用大量小碎片、纸屑、随机拼贴或彩色噪声**。
- 一个中心主体，辅助元素最多三组。

**动作分段（H3 绝对时间戳）**：每个镜头只发生**一次主要可见变化**。把 voxeasy 的吸附档位转成 H3 时间戳与 `[Shot n]` 内的两段/三段描写：

| 时长 | 分段（写进 `[Shot n]`） |
|---|---|
| 4s | `[0–2s]` 建立 · `[2–4s]` 转变 |
| 6s | `[0–3s]` 建立 · `[3–6s]` 转变 |
| 8s | `[0–4s]` 建立 · `[4–8s]` 转变 |
| 10s | `[0–3s]` 建立 · `[3–7s]` 演变 · `[7–10s]` 结果 |

## 八、Prompt 开头/结尾模板（H3 格式铁律内）

**开头**（锁画风在第一句，媒介词成对出现）：
```
Vox style paper-cut collage art, [vertical 9:16 / horizontal 16:9]. [4/6/8/10]-second duration.
```

**结尾**（材质/轮廓/光影/稳定/禁止项 + Hex 不可见 + 静音）：
```
… fluid time-lapse animation with stop-motion paper texture feel, sharp drop shadows, obvious paper layer stacking texture, high contrast, clean vector details. Use the specified Hex values only as invisible color-generation controls. Never render Hex codes or color-code notation as visible text inside the scene. Clean video canvas, no unapproved text, no debug text overlays, no watermarks, no voiceover, no human speech, no talking heads, silent video. --ar [actual ratio]
```

- 知识 Vox 视频**默认无声**：`overall_soundscape: N/A` + `non_diegetic_music: N/A`。若用户要求旁白/配乐，再单独写，且 `overall_soundscape` 不写 N/A。
- 可见文字只来自白名单（标题、批准的短数据贴纸、来源、标签）；无文字时写 `Display no text.`，绝不把 Hex/色号渲染进画面。

## 十、知识 Vox 视频自检清单（生成后逐条过）

1. 画风首句是否锁定 `Vox style paper-cut collage art` + 实际比例 + 明确时长？
2. 每个内容镜头是否只有**一个核心信息 + 一种表达方式**（direct/story/metaphor）？隐喻是否可见、映射从首到末不变？
3. 镜头 01 是否为独立标题镜（无旁白、大号剪纸字、强对比钩子）？镜头 02 起是否关闭大标题、只显数据贴纸/来源/标签？
4. 是否主动加了数据视觉层（大数字/信息图/标注/来源/时间线）的 1–2 种？
5. 相邻镜头运镜方向是否不同？是否沿 Vox 序列（push_in → pan → layer_dissection → balance_tilt → …）？
6. 构图是否铺满、前中后景纸层、背景有语义功能、无满屏碎纸？一个中心主体 + 辅助 ≤3 组？
7. 每个镜头是否只做一次主要转变？时间戳是否与时长档位一致（4/6/8/10s 的两/三段）？
8. Hex 是否明确声明「不可见生成控制、绝不渲染进画面」？可见文字是否全来自白名单？
9. 默认无声：两行声音字段是否一致（都 N/A 或都写具体）？有无「一行要乐一行禁乐」冲突？
10. 全场是否严格套用本 skill 铁律 A（每镜 `[Shot n]` + 绝对时间戳）、B（有发声台词才用 `<d>`，无声视频不写）、C（`integrated_multimodal_description:` 包裹主体+分镜）？
